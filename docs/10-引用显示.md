# 引用显示

引用单元格（`@表名` / `@枚举名` / `List<@X>` / `Set<@X>`，见 @01）在网格里默认显示原始 **id**。本文档定义「**被引用展示列**」能力：让引用列改显示目标的某一列（如名称 / 描述 / 任意字段），方便查看数据。

**范围：纯工具内显示。** 不改 `.tbl` 数据、不影响导出与生成代码（@02 引用类型字段生成仍始终存 / 出 id）。这是「展示层」的视图偏好，不是数据语义。

## 1. 目标与范围

- **一个表里多个引用列各指向不同目标**时，各列按**各自目标**的设定显示，互不影响（A 列显名称、B 列显描述、C 列仍显 id 是常态）。
- 设定**住在被引用的目标节点上**（表 / 枚举），设一次、所有指向它的引用处处生效。
- 默认**不翻译**（显 id）——保持现状，需显式开启。

## 2. 显示语义

两条规则叠加：**节点级属性 `display_field`**（§3）+ **视图级总闸**（§6）。

| 总闸（ribbon checkbox） | 引用列显示 |
|------------------------|-----------|
| 不勾（默认） | 一律显示原始 id |
| 勾上 | 该列按**它目标的 `display_field`** 取列显示；目标没设时用该类型默认：**枚举 → `name`**，表 → 原始 id |

**兜底链**：勾上总闸后，取目标 `display_field` 指定的列——
- 该列**不存在**（表被改过 / 列被删）→ 回落原始 id
- 该列**类型不合格**（不再是 str / int / txt，见 §3）→ 回落原始 id
- 该格值为空 → 回落原始 id

> **枚举默认 `name`**：枚举固定 id\|name\|desc，`name` 是天然标签，所以枚举**未显式设 `display_field` 时默认显示 `name`**（不用逐个体配置）。表没有这种天然默认——未设则显示原始 id（`ENUM_DEFAULT_DISPLAY_FIELD`，`model.rs`）。

**多选**（`List<@X>` / `Set<@X>`）：按对应分隔符（@01.7.4）拆开，逐元素按同规则显示，再用原分隔符拼回。

> 副作用：节点设了 `display_field` 但总闸没勾则不生效——需「设节点 + 勾总闸」两步。这是有意的：总闸是快速"全部看回复原始 id"的开关，节点属性是"该显哪列"的定义。

## 3. `display_field` 属性

挂在**表 / 枚举节点**上（`Table` / `EnumDef`，@02.25.3）：

```rust
// model.rs
pub display_field: Option<String>,   // None = 用类型默认（枚举→name，表→显 id）；Some(列名) = 显该列
```

取值 = 目标节点的某个**列名**：

| 目标 | 可选列 |
|------|--------|
| 枚举 | `name` / `desc`（枚举固定 id\|name\|desc，@01）；**未设默认 `name`** |
| 表 | 类型为 **`str` / `int` / `txt`** 的字段（如 `name` / `desc` / `title` / `hp`）；未设默认原始 id |

- 未设（`None`）= 用该类型默认：**枚举 → `name`**，表 → 原始 id。
- 表没有固定 name/desc 列——可选列是"该表某一合格字段"，不是"name/desc 二选一"。
- **合格列**限定为 `str` / `int` / `txt` 叶子类型：排除引用（`@X`）、复合（`List` / `Set` / `Map` / `Tuple`）以及 `long` / `float` / `double` / `bool`——避免被引用展示列本身是引用或复合值导致语义混乱。
- 属性随节点走：改名 / 退组 / 跨项目迁移后仍有效（见 §4）。

## 4. 持久化

写在 **`project.tblschema`** 的对应段里（@01.10），一行：

```
[hero/HeroType] enum
# @display: name

[hero/HeroBase] table
# @display: title
id | int | cs | 主键
name | str | cs | 名称
...
```

- 默认（`display_field` 为 `None`）时**不输出**该行。
- 位置：段头 `[group/Name] mode` 之后、字段 / `# @preset` 之前。
- 解析：段内 `# @display: <列名>` 行（现有 parse 把段内 `#` 行当注释跳过，需新增该分支，`tblschema.rs::parse_tblschema`）。

**关键：schema 只是落盘器，节点模型才是真相源。** `schema_from_project`（`tblschema.rs:393`）每次保存从 `groups` **重建** sections，段级额外字段不会留存——所以 `display_field` 必须挂在节点模型上，由 `schema_from_project` 带出、`serialize_tblschema` 写出；加载时 `.tbl` 先出节点、再用 schema 段的 `# @display` 回填节点。

写入 / 读取链路：

```
改属性（UI）→ 节点.display_field → save_project_files（脏由快照对比得出，@02.26.2）
              → sync_schema_from_groups → schema_from_project 带出 → serialize_tblschema 写出

加载：.tbl → 节点 → schema 段 # @display → 回填 节点.display_field
```

## 5. 显示解析（运行时）

改造 `crates/app-slint/src/convert/grid.rs::display_for_table_cell`（现仅遍历 `g.enums`，表引用未翻译）：

```
输入：(target 名, raw, multi, is_set)
总闸关 → 返回 raw
target 定位：先查 enums、再查 tables（名字唯一由验证层保证，@02.27 RefIndex 同源）
取列 = target.display_field；None → 枚举取 name（默认），表 → 返回 raw
列不合格（表字段非 str/int/txt，见 §3）→ 返回 raw
查值：
  枚举 → entry(id == raw).{name|desc}
  表   → row(id == raw).{列 == display_field}
空 / 列不存在 → 返回 raw
multi → 按分隔符拆开逐元素走上述，原分隔符拼回
```

**性能**：表查找需要 **id → 行** 索引（一次性建、随节点缓存），否则每个可见格扫全表，万行表滚动会卡。

调用点不变：公式栏 `cell_display`、Table 数据格、Constant value 格。

## 6. UI

| 控件 | 位置 | 作用 | 启用条件 |
|------|------|------|---------|
| **总闸 checkbox** | GridRibbon | 勾上 = 按各目标 `display_field` 显示；不勾 = 显 id | 当前节点含引用列（Table / Constant） |
| **被引用展示列下拉** | GridRibbon | 设当前节点的 `display_field`（见 §3） | 当前节点是 表 / 枚举 |

- 总闸沿用现有 checkbox，`AppState.view_show_enum_name` → `view_show_ref_name`，label 由「枚举显示名字」改为覆盖表 + 枚举的措辞（总闸仍是**会话内**状态，不持久化）。
- 被引用展示列下拉选项：
  - **表** = `ID` + 合格列（`str`/`int`/`txt` 字段，§3）；`ID` = 不转换（清空 `display_field`）
  - **枚举** = `name` / `desc`（无 `ID`——枚举默认即 `name`）；选 `name` = 清空回默认
- 改动 → 写节点 `display_field` → 保存时随 `project.tblschema` 落盘（@02.26.2）→ push grid。
- 两个控件可同屏（一个 Table 节点既可能**含**引用列，也可能**被**引用）。

## 8. 边界与非目标

- **不改** `.tbl` 数据格式、不动导出 / 生成代码。
- **不做** per-column 覆盖（列级 override）——被引用展示列住在目标节点上，不按"引用它的那一列"细分。
- 总闸是**会话内**视图状态，不持久化；持久化的只有节点 `display_field`。
- 表引用此前**从未**做过名字翻译（`display_for_table_cell` 只认枚举），本能力对表是新增，对枚举是改造。
