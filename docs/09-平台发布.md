# 平台发布

3.0 起只有 Tauri GUI + CLI 两个产物：

- **`tablet.exe` / `tablet`**（顶层）：Tauri 单文件；零参数 / `--gui [--workdir=...]` 走 GUI，
  其它参数（含子命令 / `--help`）转给内置的 `tablet-cli` lib。开发 / 策划装这一份即可。
- **`tablet-cli.exe` / `tablet-cli`**（中层）：纯命令行，体积小、不依赖 GUI 栈；
  Jenkins / CI / 服务器自动化推荐用这份。

> 客户端集成（Unity 编辑器按钮 / bat）建议用 `tablet-cli`：随 config 仓库放到 `tools/tablet/`，
> 用相对路径调用即可。Git 仓库建议用 LFS 存二进制，SVN 直接提交；不要把 `target/` 或构建脚本放进
> config 仓库。插件侧示例见 `skills/tablet/references/unity.md`。

## 1. CLI 平台兼容

`tablet-cli` 不依赖任何 GUI 栈，跟着 Rust stdlib 走：

| 平台 | 支持 | 备注 |
|------|------|------|
| Windows 10 / 11 (1809+) | ✅ | 主要测试平台；Tier 1 |
| Windows Server 2016+ | ✅ | Tier 1 |
| Windows 7 / 8 / 8.1 | ❌ | Rust stdlib 已不支持 |
| macOS 11+ | ✅ | Tier 1；release 脚本 `MACOSX_DEPLOYMENT_TARGET=11.0` |
| Linux x86_64 (glibc) | ✅ | kernel 3.2+, glibc 2.17+ |
| Linux x86_64 (musl) | ✅ | `linux-cli-musl` 目标产全静态 CLI，老 glibc / Alpine / 容器 scratch 直接跑 |
| ARM64 各平台 | ⚠ 未测 | 仅 macOS arm64 用户偶发反馈可用 |

## 2. GUI 平台兼容（Tauri）

Tauri 在 CLI 兼容矩阵之上多一层运行时依赖：

| 平台 | 支持 | 运行时要求 |
|------|------|-----------|
| Windows 11 / Windows 10 1803+ | ✅ | **WebView2 Evergreen 运行时**（Win11 自带；Win10 一般随 Edge 安装，未装需人工安装） |
| Windows 7 / 8.1 | ❌ | WebView2 已冻结在 109 |
| Linux x86_64 | ✅ | **WebKitGTK 4.1 + GTK3**（`libwebkit2gtk-4.1-0`、`libgtk-3-0`、`libsoup-3.0-0`、`libjavascriptcoregtk-4.1-0`） |
| Linux musl | ❌ | GUI 依赖 WebKitGTK 动态库，musl 只发 CLI |
| macOS 11+ | ✅ | universal（intel + arm64），未签名需右键打开 |

## 3. 构建

统一先构建 Univer 前端（`ui/univer` 被 gitignore；裸 `cargo build` 不会触发 Tauri 的
`beforeBuildCommand`）：

```bash
npm --prefix crates/app-tauri/univer-editor ci
npm --prefix crates/app-tauri/univer-editor run build
```

然后按平台构建：

```bash
# Windows（必须 msvc；gnu 会外挂 WebView2Loader.dll）
cargo build --release --target x86_64-pc-windows-msvc -p tablet -p tablet-cli

# Linux（需 WebKitGTK 4.1 / GTK3 开发包）
cargo build --release -p tablet -p tablet-cli

# macOS（universal 由 release 脚本 lipo）
cargo build --release --target x86_64-apple-darwin -p tablet -p tablet-cli
cargo build --release --target aarch64-apple-darwin -p tablet -p tablet-cli
```

或直接：

```bash
bash scripts/release.sh host      # Windows → windows；Linux → linux + linux-cli-musl；macOS → macos
```

## 4. 发布矩阵

| target | 宿主要求 | 产物 |
|--------|--------|------|
| `windows` | Windows | `dist/windows/{tablet,tablet-cli}.exe`（msvc） |
| `linux` | Linux + WebKitGTK 4.1 dev | `dist/linux/{tablet,tablet-cli}` + `.deb` |
| `linux-cli-musl` | Linux + musl-tools | `dist/linux-cli-musl/tablet-cli`（全静态） |
| `macos` | macOS | `dist/macos/{tablet,tablet-cli}` + `Tablet.app` / `.dmg` |

GitHub Releases 由 `.github/workflows/release.yml` 在 `v*` tag 时自动聚合；产物统一改名成
`tablet-<version>-<target>[.exe]` / `tablet-cli-<version>-<target>[.exe]`。

## 5. Windows 单文件约束

| 项 | 规定 |
| --- | --- |
| target | `x86_64-pc-windows-msvc`（官方只支持 MSVC；gnu 会多一个 DLL） |
| `strip` | 保持 `"debuginfo"`；pdb 不归档、不随包发 |
| `bundle.resources` | 为空 |
| `externalBin`（sidecar） | 禁用 |
| `webviewInstallMode` | `skip`；不要用 `fixedRuntime`（会多出 ~180MB 目录） |
| identifier | `com.juebanlin.tablet.tauri`，定一次不再改（决定 WebView2 user data 目录） |

允许落盘的位置：WebView2 user data 在 `%LOCALAPPDATA%\<identifier>`；业务 / 崩溃日志在 `workdir`
（`tablet.log` / `tablet-crash.log`），与 exe 位置无关。

## 6. 已知不支持

- 不提供安装器（NSIS/MSI）；`tablet.exe` 是绿色单文件。
- 不在安装包里捆绑 WebView2；目标机器没有运行时时需人工安装 Evergreen 运行时。
- macOS 产物未签名 / 未公证，Gatekeeper 会拦截，需右键打开。
- 不发 Win7/8.1 包。
