# 平台发布

3.0 起只有 Tauri GUI + CLI 两个产物：

- **`tablet.exe` / `tablet`**（顶层）：Tauri 单文件；零参数 / `--gui [--workdir=...]` 走 GUI，
  其它参数（含子命令 / `--help`）转给内置的 `tablet-cli` lib。开发 / 策划装这一份即可。
- **`tablet-cli.exe` / `tablet-cli`**（中层）：纯命令行，体积小、不依赖 GUI 栈；
  Jenkins / CI / 服务器自动化推荐用这份。

> 客户端集成（Unity 编辑器按钮 / bat）建议用 `tablet-cli`：随 config 仓库放到 `tools/tablet/`，
> 用相对路径调用即可。Git 仓库建议用 LFS 存二进制，SVN 直接提交；不要把 `target/` 或构建脚本放进
> config 仓库。插件侧示例见 `skills/tablet/references/unity.md`。

## 1. 基线：Rust 与 Tauri

- **Rust**：主线使用 stable。Rust 1.78 起 Tier 1 Windows 目标最低 Windows 10；Win7 必须用
  Tier 3 `x86_64-win7-windows-msvc` + nightly `-Z build-std`（兼容包脚本负责）。
- **Tauri**：2.x。Windows 用 WebView2；Linux 用 WebKitGTK **4.1**；macOS 最低 10.15。
- **开发构建**：`cargo build -p tablet` / `cargo tauri dev` 始终是**当前平台最新基线**；
  老平台兼容包由独立脚本产出，不混进日常构建。

## 2. 发布产物与兼容范围

主线产物（直接可用的普通文件）：

| 文件 | 平台 / 最低版本 | 形态 | 运行时要求 | 说明 |
|---|---|---|---|---|
| `tablet-<ver>-windows10-1803-x64.exe` | Windows 10 1803+ / 11 x64 | 便携 GUI | WebView2（Win11 自带；Win10 一般随 Edge 安装） | 推荐 |
| `tablet-cli-<ver>-windows-x64.exe` | Windows 10 x64 | CLI | 无 | Jenkins / 自动化 |
| `tablet_<ver>_amd64.deb` | Ubuntu 22.04+ / Debian 12+ | deb | WebKitGTK 4.1 | apt 安装 |
| `tablet-<ver>-linux22.04-x64` | 同上（glibc 2.35+） | 便携 GUI | WebKitGTK 4.1 / GTK3 | 解压即用 |
| `tablet-cli-<ver>-linux-musl-x64` | 任意 x86_64 Linux | 静态 CLI | 无 | 老 glibc / Alpine / 容器 |
| `tablet-<ver>-macos10.15-universal` | macOS 10.15+ | universal 可执行文件 | 系统 WKWebView | 已包含在 `Tablet.app` 内 |
| `Tablet-<ver>.dmg` / `Tablet-<ver>.app.zip` | macOS 10.15+ | 安装包 / 便携包 | 同上 | 与 zip 内容一致 |

老平台兼容包（文件名直接写兼容范围）：

| 文件 | 平台 / 兼容范围 | 形态 | 运行时要求 |
|---|---|---|---|
| `tablet-<ver>-windows-legacy-win7-win10lt1803-x64.zip` | Win7 SP1 / 8.1 / Win10 1803 之前 | ZIP 套件 | 固定版 WebView2 **109**（最后一个支持 Win7/8.1 的版本） |

> Win7 legacy 包用 nightly `x86_64-win7-windows-msvc` + `-Z build-std` 编译；WebView2 109
> 自 2023 年后不再更新。该包**仅实验性**，需 Win7 SP1 真机验收。CI 无法从微软稳定自动下载
> 109 固定版，zip 内提供放置说明；本地构建可用 `WEBVIEW2_FIXED_RUNTIME_DIR=<目录>` 打入运行时。
>
> Linux 没有“22.04 之前的纯二进制包”：Tauri 2 硬性要求 WebKitGTK 4.1，Ubuntu 20.04 /
> Debian 11 只有 4.0。老发行版只能用 Flatpak（自带运行时）或只使用 `tablet-cli` 的 musl 包。

## 3. 构建

统一先构建 Univer 前端（`ui/univer` 被 gitignore；裸 `cargo build` 不会触发 Tauri 的
`beforeBuildCommand`）：

```bash
npm --prefix crates/app-tauri/univer-editor ci
npm --prefix crates/app-tauri/univer-editor run build
```

然后按平台构建：

```bash
# Windows（必须 msvc；gnu 会外挂 WebView2Loader.dll）
cargo build --release --target x86_64-pc-windows-msvc -p tablet -p tablet-cli

# Linux（需 WebKitGTK 4.1 / GTK3 开发包）
cargo build --release -p tablet -p tablet-cli

# macOS（universal 由 release 脚本 lipo；最低 10.15）
cargo build --release --target x86_64-apple-darwin -p tablet -p tablet-cli
cargo build --release --target aarch64-apple-darwin -p tablet -p tablet-cli
```

或直接：

```bash
bash scripts/release.sh host             # 主线：Windows / Linux / macOS
bash scripts/build-windows-legacy.sh     # 老 Windows 兼容包（Win7 ~ Win10 <1803）
```

## 4. 发布矩阵

| target | 宿主要求 | 产物 |
|--------|--------|------|
| `windows` | Windows | `dist/windows/{tablet,tablet-cli}.exe`（msvc；CI 改名为 `windows10-1803`） |
| `linux` | Linux + WebKitGTK 4.1 dev | `dist/linux/{tablet,tablet-cli}` + `.deb` |
| `linux-cli-musl` | Linux + musl-tools | `dist/linux-cli-musl/tablet-cli`（全静态） |
| `macos` | macOS | `dist/macos/{tablet,tablet-cli}` + `Tablet.app` / `.dmg` |
| `windows-legacy` | Windows + nightly + rust-src | `dist/windows-legacy/*.zip`（Win7 ~ Win10 <1803） |

GitHub Releases 由 `.github/workflows/release.yml` 在 `v*` tag 时自动聚合；Release notes 中
按上面的兼容表逐行列出文件、最低版本、形态与运行时要求。

## 5. Windows 单文件约束

| 项 | 规定 |
| --- | --- |
| target | `x86_64-pc-windows-msvc`（官方只支持 MSVC；gnu 会多一个 DLL） |
| `strip` | 保持 `"debuginfo"`；pdb 不归档、不随包发 |
| `bundle.resources` | 为空 |
| `externalBin`（sidecar） | 禁用 |
| `webviewInstallMode` | `skip`；不要用 `fixedRuntime`（会多出 ~180MB 目录） |
| identifier | `com.juebanlin.tablet.tauri`，定一次不再改（决定 WebView2 user data 目录） |

允许落盘的位置：WebView2 user data 在 `%LOCALAPPDATA%\<identifier>`；业务 / 崩溃日志在 `workdir`
（`tablet.log` / `tablet-crash.log`），与 exe 位置无关。

## 6. 已知不支持

- 不提供安装器（NSIS/MSI）；`tablet.exe` 是绿色单文件。
- 不在安装包里捆绑 WebView2；目标机器没有运行时时需人工安装 Evergreen 运行时。
- macOS 产物未签名 / 未公证，Gatekeeper 会拦截，需右键打开。
- 主线不发 Win7/8.1 包；老 Windows 用独立的 legacy zip（实验性）。
