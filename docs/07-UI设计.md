## 左侧树形结构

### 交互方式

| 操作 | 效果 |
|------|------|
| 点击三角形(▶/▼) | 展开/收拢组 |
| 双击组名 | 展开/收拢组 |
| 单击配置项 | 选中，右侧显示详情 |
| 右键任意位置 | 弹出对应上下文菜单 |

### 状态标记

节点名后显示彩色状态标记：

| 标记 | 颜色 | 含义 |
|------|------|------|
| `+` | 绿色 | 新建，未保存到磁盘 |
| `*` | 黄色 | 已有文件被修改 |
| `-` | 红色 | 标记删除，保存时生效 |

组的状态聚合子项：所有子项删除→`-`，有新建子项或自身新建→`+`，有修改子项→`*`。

判断逻辑：
- 新建：`original` 为空（从未保存过）
- 修改：序列化当前内容 ≠ `original`（支持"改回去"自动清除脏标记）
- 删除：`deleted` 标记为 true

### 过滤器

树顶部有下拉过滤框：

| 选项 | 显示内容 |
|------|----------|
| 全部 | 所有节点 |
| 改动 | 新增 + 修改 + 删除 |
| 新增 | 仅新建节点 |
| 修改 | 仅已修改节点 |
| 删除 | 仅标记删除节点 |

非"全部"模式下，空组自动隐藏。可勾选"完整组"显示匹配组的所有子项。

### 右键菜单

| 目标 | 菜单项 |
|------|--------|
| Group 节点 | 新建 Table、新建 Constant、重命名、删除 |
| Table/Constant 节点 | 复制、重命名、删除 |
| 空白区域 | 新建 Group |

## 表格区

### 单元格类型系统（CellKind）

所有单元格统一抽象为 CellKind，通过类型决定交互行为：

| 类型 | 交互方式 | 用途 |
|------|----------|------|
| ReadOnly | 不可编辑 | 常量表固定表头 |
| Text | 双击编辑 | 普通数据、表头描述/字段名 |
| TypeEnum | 单击下拉 | 表头 type 行单元格 |
| ExportEnum | 单击下拉 | 表头 export 行单元格 |
| TypeEnumCol | 单击下拉 | 常量表 type 列（整列继承） |
| ExportEnumCol | 单击下拉 | 常量表 export 列（整列继承） |
| Ref | 单击弹窗 | 引用类型字段（@TableName / @EnumName），统一弹窗选择 |

### 存储值 vs 展示值（重要约定）

单元格在 UI 模型层（`grid.data` / `HeaderCell.text`）**始终存「真实存储值」**——即写入 .tbl 文件的形式。渲染层在画的瞬间通过 `display_for_*` 转换为给人看的形式。

| 列类型 | 存储值（grid.data / HeaderCell.text） | 展示值（painter 输出） |
|--------|---------------------------------------|------------------------|
| ExportEnum / ExportEnumCol | `cs` / `c` / `s` / `-` | 前后端 / 客户端 / 服务器 / 不导出 |
| Ref（@EnumName，「枚举显示名字」开启时） | enum 条目 id（如 `1`） | 对应 entry 的 name（如 `WARRIOR`） |
| Ref（@TableName 或开关关闭） | 表/枚举 id | 同存储值 |
| 其它 | 原始字符串 | 同存储值 |

由此自动得到的好处：
- **复制粘贴 round-trip**：剪贴板里永远是 `cs` 而不是 `前后端`，粘到别处也能直接落地
- **公式栏/编辑缓冲一致**：编辑态读 `grid.data` 直接拿到存储值
- **校验/序列化无歧义**：底层逻辑只看一种字符串

下拉编辑组件的同一侧也按此规则：`edit_buffer` 写入存储值（如点击「前后端」实际写 `cs`），渲染时再翻译。新增带「展示≠存储」的列类型时，**必须同时在 `display_for_cell` / `display_for_header` 增加分支**，不允许把展示值塞回 `grid.data`。

### Table 模式

4行固定表头 + 可滚动数据区：

```
┌────┬──────┬──────┬──────┬────────┐
│    │  A   │  B   │  C   │   D    │  ← 列字母行
├────┼──────┼──────┼──────┼────────┤
│    │英雄ID│ 名称 │ 血量 │ 技能组 │  ← desc (Text, 双击编辑)
│    │前后端│前后端 │服务器│ 前后端 │  ← export (ExportEnum, 单击下拉)
│    │ int  │ str  │ int  │IntArray│  ← type (TypeEnum, 单击下拉)
│    │ id   │ name │ hp   │ skills │  ← field (Text, 双击编辑; ID列为ReadOnly)
╞════╪══════╪══════╪══════╪════════╡
│  1 │ 1001 │ 战士 │ 100  │ 1;2;3  │  ← 数据行 (Text, 双击编辑)
│  2 │ 1002 │ 法师 │  80  │ 4;5    │
│  3 │      │      │      │        │  ← 扩展空行（自动追加5行）
└────┴──────┴──────┴──────┴────────┘
```

- 表头固定不随数据滚动
- 数据行数 = 第一列（ID列）非空的行数
- 扩展空行允许直接输入新增数据
- ID列（主键列）字段名固定为 `id`，不可编辑、不可删除

### Constant 模式

1行固定表头 + 可滚动数据区：

```
┌────┬──────────┬──────┬───────┬──────┬──────────┐
│    │  A       │  B   │  C    │  D   │  E       │
├────┼──────────┼──────┼───────┼──────┼──────────┤
│    │ name     │ type │ value │export│ desc     │  ← 固定表头 (ReadOnly)
╞════╪══════════╪══════╪═══════╪══════╪══════════╡
│  1 │max_level │ int▾ │ 100   │前后端▾│最大等级  │
│  2 │start_pos │IntPair▾│ 5,10│前后端▾│出生坐标  │
└────┴──────────┴──────┴───────┴──────┴──────────┘
```

列定义：
- name (Text) / type (TypeEnumCol▾) / value (Text) / export (ExportEnumCol▾) / desc (Text)

### Enum 模式

固定 3 列表头 + 可滚动数据区，无 type/export 列：

```
┌────┬──────┬──────────┬──────────┐
│    │  A   │  B       │  C       │
├────┼──────┼──────────┼──────────┤
│    │  id  │ name     │ desc     │  ← 固定表头 (ReadOnly)
╞════╪══════╪══════════╪══════════╡
│  1 │  1   │ WARRIOR  │ 战士     │
│  2 │  2   │ MAGE     │ 法师     │
│  3 │  3   │ ARCHER   │ 弓手     │
└────┴──────┴──────────┴──────────┘
```

列定义：
- id (Text，正整数 + 唯一 + ≠0) / name (Text，UPPER_SNAKE_CASE) / desc (Text，任意文本)

## 功能区 bar

位于工具栏与编辑栏之间，类似 Excel 工具栏下面那条「字体/对齐/换行」选项条：放置**视图开关**，仅影响表格渲染，不改数据、不改公式栏行为。

```
┌─────────────────────────────────────────────────────────┐
│ [☑] 枚举显示名字   ...                                  │
└─────────────────────────────────────────────────────────┘
```

### 当前开关

| 开关 | 作用 | 默认 |
|------|------|------|
| 枚举显示名字 | 引用枚举（@EnumName）的单元格只读渲染时，显示 enum 条目的 name 而非 id；不影响公式栏（编辑时仍是 id） | 关 |

### 不参与切换

- **表引用**（@TableName）始终显示 id —— 引用表可能没有 `name` 字段，无统一名字可显示
- **编辑场景**（公式栏 / 双击编辑）始终显示 id —— 避免「看到名字、改的是 id」的割裂

### 后续扩展位置

功能区按横向 ToolStrip 布局，未来可加入：隐藏空列 / 高亮验证错误行 / ...（首版只实现"枚举显示名字"）。

## 编辑栏（公式栏）

位于功能区下方、表格上方，类似 Excel 公式栏：
- 左侧显示当前选中单元格坐标（如 "B3"）
- 右侧显示/编辑单元格完整内容

- 引用类型显示**永远是 id**（编辑时一致），不受功能区开关影响

## 保存机制

### 延迟写盘

所有创建/修改/删除操作仅修改内存，不立即写磁盘：
- 新建 Group/Table/Constant → 内存中创建，标记 `is_new` / `dirty`
- 编辑数据 → 修改内存，通过序列化对比自动计算 dirty
- 删除 → 标记 `deleted`，节点仍在树中显示（带 `-`）
- 复制 → 内存中复制，标记为新建

### 保存按钮

点击保存时统一处理：
1. 新建组 → `create_dir_all`
2. dirty 的 Table/Constant → 序列化写入 .tbl 文件
3. deleted 的节点 → 删除 .tbl 文件，从内存移除
4. 空组 → 删除目录

未保存关闭程序 = 丢弃所有修改。

### 进程锁

同目录下 `.tbl-tool.lock` 文件防止多实例编辑同一项目。启动时检查 PID 是否存活。

| 勾选/取消 | 同导出的树勾选逻辑 |
| 点击"导入" | 将选中项的表结构写入项目（覆盖同名项） |

冲突状态标记：

| 标记 | 含义 |
|------|------|
| ✅ 新增 | 项目中不存在该配置项，直接创建 |
| ⚠️ 已存在(将覆盖) | 项目中已有同名配置项，导入将覆盖其表结构 |

底部状态行显示已选数量和冲突覆盖数量。用户可通过取消勾选来跳过不想覆盖的项。

#### 通用交互规则

- 树节点展开/收拢通过点击组名前的三角形
- 勾选框与节点文字均可点击切换选中状态
- 对话框支持 Esc 关闭（等同取消）
- 导入/导出完成后在日志栏输出操作结果

### 引用类型选择器（@TableName / @EnumName）

引用类型字段（`@Xxx`）单元格点击触发**统一弹窗**（不分下拉/弹窗阈值），结构：

```
┌──────── 选择 HeroType ────────────────┐
│ 搜索: [_________________________]      │
├────────────────────────────────────────┤
│ id  │ name     │ desc                  │
├─────┼──────────┼───────────────────────┤
│ 1   │ WARRIOR  │ 战士                  │
│ 2   │ MAGE     │ 法师                  │
│ 3   │ ARCHER   │ 弓手                  │
│ ... │ ...      │ ...                   │
├────────────────────────────────────────┤
│             [清除] [取消]  [确定]      │
└────────────────────────────────────────┘
```

| 引用类型 | 弹窗列 | 说明 |
|---------|-------|------|
| `@EnumName`（枚举引用） | id / name / desc 三列 | 选中后存 id（int） |
| `@TableName`（表引用） | id 列 + 如有 `name` 字段则追加 name 列 | 选中后存 id（int） |

交互：
- 搜索框模糊匹配任意可见列
- 双击行 = 确定
- [清除] 把单元格置空（视作未引用）
- 引用值为空时单元格视觉淡灰

### 单元格显示

### 使用建议

- egui 默认字体支持大部分 Unicode emoji 渲染
- 组合符号（如 ⚠️ = U+26A0 + U+FE0F）在某些字体下可能显示为文本样式
- 单色符号（▶▼☑☐▣●○）渲染最稳定
- 彩色 emoji（📁📊🟢）依赖系统字体，Windows/macOS 表现一致

### 框架兼容性

| 框架 | 彩色 emoji | 单色符号 | 备注 |
|------|-----------|----------|------|
| egui | ✅ 支持 | ✅ 支持 | 走系统字体 fallback，开箱即用 |
| Slint | ✅ 支持 | ✅ 支持 | 需确保字体 fallback 链含 emoji 字体 |
| fltk | ❌ 不支持 | ✅ 支持 | 字体引擎不解析 color emoji 表（COLR/CBDT/sbix） |

**fltk 限制说明：**

- FLTK 能加载自定义 TTF，但彩色 emoji 只会渲染为单色轮廓或方框
- 没有成熟的第三方库能让 FLTK 原生支持彩色 emoji
- 变通方案：用 `Fl_SVG_Image` / `Fl_PNG_Image` 贴图替代（维护成本高）
- 推荐替代方案：放弃彩色 emoji，用单色符号 + 文字颜色区分

**fltk 兼容替代方案：**

| 当前 emoji | fltk 替代 | 颜色 |
|-----------|-----------|------|
| 📁 | `[G]` 或 `▪` | 绿色 |
| 📊 | `[T]` 或 `◆` | 蓝色 |
| 📋 | `[C]` 或 `◇` | 橙色 |
| ✅ | `✓` | 绿色 |
| ⚠️ | `!` | 黄色 |
| ❌ | `✕` | 红色 |

如果未来需要切换到 fltk，只需替换图标常量定义即可，不影响业务逻辑。
