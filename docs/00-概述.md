# TBL 配置管理系统 — 概述

## 系统定位

游戏配置数据管理工具链，解决策划用 Excel 编辑配置表时的协作冲突、版本管理和代码生成问题。

**核心思路：** Excel 只作为编辑器，数据以文本中间格式（.tbl）存储在 Git 中，通过工具实现 Excel ↔ .tbl 双向转换。

**技术栈：** 服务端 Java，客户端 Unity/Cocos 的 Lua。

## 工作流

```
策划日常流程：

打开 tbl-tool → 左侧树选择配置表 → 在 UI 内直接编辑 / 点击"用 Excel 打开"
    → 编辑完成 → 验证通过 → 点击保存 → .tbl 文件更新
    → git commit / push

程序日常流程：

git pull → tbl-tool export → 生成 server/data + server/code + client
    → 编译运行
```

**冲突策略：** 不做本地并发锁，完全依赖 Git 解决冲突。一行一记录的文本格式保证大多数情况下 Git 可自动 merge。

## 核心概念

| 概念 | 说明 |
|------|------|
| Group | config/ 下的一个文件夹，对应一个 Excel 文件 |
| Table | 行列数据配置（.tbl，mode=table） |
| Constant | 离散常量配置（.tbl，mode=constant） |
| Export | 导出标记：前后端 / 客户端 / 服务器 / 不导出 |
