# 验证规则

保存时自动执行验证，验证失败会阻止保存并在日志框输出具体错误位置。

## Table 验证

| 规则 | 说明 | 错误示例 |
|------|------|----------|
| ID 必须是数字 | index 列的值只能是整数 | `ID "abc" 必须是数字` |
| ID 不能重复 | 同一 Table 内 index 列值唯一 | `ID "1001" 重复` |

空行（ID 为空）跳过验证。

## Constant 验证

| 规则 | 说明 | 错误示例 |
|------|------|----------|
| name 不能含空格 | 编辑时自动 trim + 去除中间空格 | `name "max level" 不能含空格` |
| name 必须是合法标识符 | 字母或下划线开头，仅含字母数字下划线 | `name "123abc" 不是合法标识符` |
| name 不能是语言关键字 | Java 和 Lua 关键字均禁止 | `name "class" 是语言关键字` |
| name 不能重复 | 同一 Constant 内 name 唯一 | `name "maxLevel" 重复` |

空行（name 为空）跳过验证。

## 自动修正

| 场景 | 处理 |
|------|------|
| 常量 name 编辑/粘贴 | 自动 trim 两端空格，去除中间空格 |

## Java 关键字列表

```
abstract, assert, boolean, break, byte, case, catch, char, class, const,
continue, default, do, double, else, enum, extends, final, finally, float,
for, goto, if, implements, import, instanceof, int, interface, long, native,
new, package, private, protected, public, return, short, static, strictfp,
super, switch, synchronized, this, throw, throws, transient, try, void,
volatile, while, true, false, null
```

## Lua 关键字列表

```
and, break, do, else, elseif, end, false, for, function, goto, if, in,
local, nil, not, or, repeat, return, then, true, until, while
```

## 后续可扩展

- 字段名合法性（生成代码用）
- 表头完整性（必须有 index 字段）
