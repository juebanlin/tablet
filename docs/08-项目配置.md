# 项目配置

## tbl-tool.toml

```toml
[project]
name = "game-config"
config_dir = "config"
cache_dir = ".tbl-cache"

[export.server]
lang = "java"
package = "com.game.config"
data_output = "gen/server/data"
code_output = "gen/server/code"

[export.client]
lang = "lua"
output = "gen/client"

[ui]
auto_commit_on_blur = true
realtime_validate = false
log_level = "debug"

[separators]
Tuple2 = ","
Tuple3 = ","
Tuple4 = ","
List = ";"
Set = ";"

[separators.Map]
kv = ":"
entry = ";"

[separators.List_Tuple2]
tuple = ","
list = ";"

[separators.Map_Tuple2]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_List]
kv = ":"
item = ","
entry = ";"
```

## 字段说明

### [project]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| name | 项目名称 | — |
| config_dir | .tbl 文件所在目录（相对项目根） | — |
| cache_dir | 临时 xlsx 缓存目录 | `.tbl-cache` |

### [export.server]

| 字段 | 说明 |
|------|------|
| lang | 后端语言（java / go） |
| package | Java 包名 |
| data_output | 后端数据文件输出目录 |
| code_output | 后端模板类输出目录 |

### [export.client]

| 字段 | 说明 |
|------|------|
| lang | 前端语言（lua） |
| output | 前端文件输出目录 |

### [ui]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| auto_commit_on_blur | 点击空白区域时自动保存当前编辑 | true |
| realtime_validate | 编辑单元格时实时验证 | false |
| log_level | 日志级别 (debug/info/warn/error) | debug |

### [separators]

按范式配置类型分隔符，详见 [02-类型系统](02-类型系统.md#分隔符配置)。

默认值覆盖绝大多数场景，仅当项目有历史数据使用不同分隔符时需修改。
