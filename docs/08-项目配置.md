# 项目配置

## tbl-tool.toml

```toml
[project]
name = "game-config"
config_dir = "config"
cache_dir = ".tbl-cache"

[export.server]
lang = "java"
package = "com.game.config"
data_output = "gen/server/data"
code_output = "gen/server/code"

[export.client]
lang = "lua"
output = "gen/client"

[ui]
auto_commit_on_blur = true
```

## 字段说明

| 字段 | 说明 |
|------|------|
| project.name | 项目名称 |
| project.config_dir | .tbl 文件所在目录（相对项目根） |
| project.cache_dir | 临时 xlsx 缓存目录 |
| export.server.lang | 后端语言（java） |
| export.server.package | Java 包名 |
| export.server.data_output | 后端数据文件输出目录 |
| export.server.code_output | 后端模板类输出目录 |
| export.client.lang | 前端语言（lua） |
| export.client.output | 前端文件输出目录 |
| ui.auto_commit_on_blur | 点击空白区域时是否自动保存当前编辑（默认 true，false 则只有回车才保存） |
