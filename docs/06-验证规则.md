# 验证规则

## 架构

三层验证函数，层层复用：

```
validate_cell(table/constant, row, col) → Option<&str>     单元格级
validate_row(table/constant, row)       → Vec<(col, msg)>  行级（调用 cell + 行逻辑）
revalidate(group, name)                 → 更新 errors 集合  节点级（遍历行 + 跨行逻辑）
```

- **单元格验证**：根据列类型（ID列、常量name列等）验证单个值
- **行验证**：调用所有列的单元格验证 + 行级逻辑（如有数据但ID为空）
- **节点验证**：遍历所有行 + 跨行逻辑（如ID重复、name重复）

## 配置

```toml
[ui]
# 编辑单元格时实时验证（默认关闭，保存时始终验证）
realtime_validate = false
```

## 视觉反馈

| 位置 | 表现 |
|------|------|
| 表格单元格 | 红色边框 (1.5px) |

## Table 验证

### ID列约束

- ID列字段名固定为 `id`，UI 不允许编辑
- ID列不可删除
- 每个 Table 有且仅有一个 ID 列（第一列）

### 单元格级 (validate_table_cell)

| 列类型 | 规则 | 错误信息 |
|--------|------|----------|
| ID列(index) | 值必须是整数 | "ID必须是数字" |

### 行级 (validate_table_row)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 调用所有列的 cell 验证 | — | — |
| 有数据但ID为空 | 非ID列有值但ID列为空 | "有数据但ID为空" |

### 节点级 (revalidate)

| 规则 | 说明 |
|------|------|
| ID 不能重复 | 同一 Table 内 index 列值唯一 |

## Constant 验证

### 单元格级 (validate_constant_cell)

| 列 | 规则 | 错误信息 |
|----|------|----------|
| name (col 0) | 必须符合字段命名规则 | "不是合法常量名（需小写字母开头，只含小写字母/数字/下划线）" |
| name (col 0) | 不能是 Java/Lua/Go 关键字 | "是语言关键字" |

### 行级 (validate_constant_row)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 调用所有列的 cell 验证 | — | — |
| name 已填但 value 为空 | name 非空时 value 必须有值 | "name已填但value为空" |

### 节点级 (revalidate)

| 规则 | 说明 |
|------|------|
| name 不能重复 | 同一 Constant 内 name 唯一 |

## Enum 验证

### 单元格级 (validate_enum_cell)

| 列 | 规则 | 错误信息 |
|----|------|----------|
| id (col 0) | 必须是正整数 | "id 必须是正整数" |
| id (col 0) | 不能为 0 | "id 不能为 0（保留为未设置语义）" |
| name (col 1) | 必须符合枚举条目命名规则（UPPER_SNAKE_CASE） | "不是合法枚举条目名（需大写字母开头，只含大写字母/数字/下划线）" |
| name (col 1) | 不能是 Java/Lua/Go 关键字 | "是语言关键字" |

### 行级 (validate_enum_row)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 调用所有列的 cell 验证 | — | — |
| name 已填但 id 为空 | 三列必须同步存在 | "name已填但id为空" |

### 节点级 (revalidate)

| 规则 | 说明 |
|------|------|
| id 不重复 | 同一 enum 内 id 唯一 |
| name 不重复 | 同一 enum 内 name 唯一 |

## 引用验证 (validate ref)

`@Xxx` 类型字段的值校验，按被引用项的 mode 分发：

| 被引用项状态 | 处理 | 错误信息 |
|-------------|------|----------|
| 不存在 | 字段类型本身非法 | "引用的配置项 X 不存在" |
| `mode = enum` | 值必须是该 enum 的某个 id | "引用值 5 不存在于 HeroType" |
| `mode = table` | 值必须是该表存在的 id | "引用值 1099 不存在于 HeroBase" |
| `mode = constant` | 类型本身非法 | "不能引用 constant（无 id 概念）" |

引用值为空 → 合法（视作"未引用"）。

被引用对象删除/重命名时：
- 检测谁还在引用，给警告（不阻断保存）
- 用户自行清理或调整

## 自动修正

| 场景 | 处理 |
|------|------|
| 常量 name 编辑/粘贴 | 自动 trim 两端空格，去除中间空格 |

## 命名验证

### 字段名 (Table 字段 / Constant name)

三语言交集规则：

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 不能为空 | — | "字段名不能为空" |
| 小写字母开头 | 不允许下划线/大写/数字开头 | "不是合法字段名（需小写字母开头，只含小写字母/数字/下划线）" |
| 只含小写字母/数字/下划线 | snake_case 约定 | 同上 |
| 不能是语言关键字 | Java + Lua + Go 关键字 | "是语言关键字" |

生成时各语言自动转换：
- Java → camelCase（`max_level` → `maxLevel`）
- Go → PascalCase（`max_level` → `MaxLevel`）
- Lua → 保持原样

### 组名 (Group)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 不能为空 | — | "名称不能为空" |
| 支持中英文下划线 | 只允许 `[a-zA-Z0-9_一-鿿]` | "组名只能包含中英文数字下划线" |
| 跨组不能重复 | 忽略大小写（AA 和 Aa 算重复） | "组名重复（忽略大小写）" |

> **Group 仅在工具内部使用**：树形导航 + `config_dir` 下的目录名。**不出现在生成代码、import 路径、数据文件路径中**（生成层完全扁平化），所以允许中文。详见 `09-导出功能.md`「目录扁平化」。

### 配置项名 (Table / Constant / Enum)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 不能为空 | — | "名称不能为空" |
| Java 类名规则 | 大写字母开头，只允许 `[a-zA-Z0-9_]`，不能纯数字开头 | "配置项名必须符合Java类名规则" |
| 跨组不能重复 | 所有组的 Table + Constant + Enum 名称忽略大小写不能重复 | "配置项名重复（忽略大小写）" |

### 枚举条目名 (Enum entry name)

| 规则 | 说明 | 错误信息 |
|------|------|----------|
| 不能为空 | — | "枚举条目名不能为空" |
| UPPER_SNAKE_CASE | `[A-Z][A-Z0-9_]*`（大写字母开头，只含大写字母/数字/下划线） | "不是合法枚举条目名" |
| 不能是语言关键字 | Java + Lua + Go 关键字交集 | "是语言关键字" |
| 同一枚举内不重名 | — | "枚举条目名重复" |

各语言生成时直接使用原 name（无需大小写转换）：
- Java：`HeroTypeEnum.WARRIOR`（enum 常量惯例）
- Go：`HeroTypeEnum_WARRIOR`（包级常量）
- Lua：`HeroType.WARRIOR`（表 key）

## 表头验证 (validate_table_schema / validate_constant_schema / validate_enum_schema)

导出前或保存时调用，检查结构定义的完整性：

### Table 表头

| 检查项 | 说明 |
|--------|------|
| 字段列表非空 | 表必须至少有一个字段 |
| 第一列为 id | 主键固定为第一列 `id` |
| 字段名合法 | 每个字段名符合命名规则 |
| 字段名不重复 | 同表内字段名唯一 |
| 类型合法 | 每个字段的 tbl_type 能被 `TblType::parse()` 解析 |
| 引用类型有效 | `@Xxx` 字段的被引用对象存在且非 constant |
| 主键值不重复 | 数据行中主键列的值唯一 |

### Constant 表头

| 检查项 | 说明 |
|--------|------|
| 常量名合法 | 每个非空 name 符合命名规则 |
| 常量名不重复 | 同表内 name 唯一 |
| 类型合法 | 每个条目的 tbl_type 能被解析（不允许引用类型） |

> Constant 字段**不允许**使用 `@Xxx` 引用类型——constant 是固定值，不应承载跨表关联语义。

### Enum 表头

| 检查项 | 说明 |
|--------|------|
| 至少一个条目 | 枚举不能为空 |
| id 都为正整数且非 0 | id 是枚举的稳定标识 |
| id 不重复 | 同枚举内 id 唯一 |
| name 合法 | UPPER_SNAKE_CASE，非关键字 |
| name 不重复 | 同枚举内 name 唯一 |

## 类型值验证 (validate_value)

根据字段声明的类型范式，验证数据单元格的值格式：

| 检查项 | 说明 |
|--------|------|
| 基础类型格式 | int/long 必须是整数，float/double 必须是数字，bool 必须是 true/false，str 不验证 |
| 元组不能为空 | Tuple2/3/4 类型的字段值不允许为空（空值无法给出安全默认值，必须显式填写） |
| 元组元素数量 | 按分隔符 split 后数量必须与 Tuple 声明一致 |
| 元组元素类型 | 每个位置的值必须匹配对应的基础类型 |
| 集合元素类型 | List/Set 每个元素必须匹配声明的基础类型 |
| Map 格式 | 每个条目必须包含 kv 分隔符，key/value 类型匹配 |
| 空元素检测 | 连续分隔符产生的空值（如 `1;;3`、`1,,2`） |
| 中文标点检测 | 含有 `，；：、` 中文标点 |

验证使用 `tbl-tool.toml` 中 `[separators]` 配置的分隔符进行 split。

错误信息附带示例（示例也使用配置的分隔符）：
```
列表元素类型不匹配, 示例: 1;2;3
```
