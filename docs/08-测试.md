# 测试

## 1. 测试架构

测试体系以 shell 脚本为主体，通过调用 `tablet-cli` 二进制验证所有 CLI 命令的正确性。辅以 Python 脚本生成大量随机测试数据用于性能测试。

### 1.1 设计原则

- **shell 为主体**：CLI 是 shell 工具，测试也用 shell 驱动
- **临时目录隔离**：每个测试用 `mktemp -d` 创建独立 workspace，测试完自动清理（trap EXIT）
- **无残留**：测试不在 tests/ 目录下产生任何持久文件
- **Python 仅做数据工厂**：被 shell 调用生成大量 .tbl 数据行

### 1.2 核心流程

```
tests/run_all.sh
    ├── 遍历 01_project/ ~ 11_e2e/ 下所有 test_*.sh
    ├── 每个 test_*.sh:
    │   ├── source helpers/common.sh
    │   ├── setup_workspace（创建临时 workdir + 项目）
    │   ├── run_cli ... → 断言 exit code / stdout / stderr / 文件存在
    │   └── cleanup（自动，trap EXIT）
    └── 汇总 PASS / FAIL
```

### 1.3 内置 Schema 文件

位于 `crates/core/schemas/`，测试用副本在 `tests/schemas/`：

| 文件 | 用途 |
|------|------|
| `standard.tblschema` | 通用测试（所有基础类型 + 集合 + 元组 + 引用 + 常量 + 枚举） |
| `sanguo.tblschema` | 大数据量性能测试（100+ 行预设，8 枚举，6 表） |
| `minimal.tblschema` | 最小测试（单 group + 单 table，快速验证） |

## 3. 运行方式

```bash
# 前置：编译 CLI（release 模式，性能测试需要）
cargo build -p tablet-cli --release

# 运行全部测试
bash tests/run_all.sh

# 跳过性能测试（CI 快速模式）
bash tests/run_all.sh --skip-perf

# 运行指定目录
bash tests/run_all.sh 01_project

# 运行单个测试文件
bash tests/01_project/test_new.sh
```

## 4. helpers/common.sh 公共函数

| 函数 | 用途 |
|------|------|
| `setup_workspace [template]` | 创建临时 workdir + 从模板创建项目 |
| `setup_empty_workspace` | 创建空临时 workdir |
| `cleanup` | 删除临时 workdir（trap EXIT 自动调用） |
| `run_cli <args...>` | 调用 CLI（自动带 -w $WORK_DIR） |
| `run_cli_raw <args...>` | 调用 CLI（不带 -w，util 命令用） |
| `assert_exit <code>` | 断言上次 CLI 调用的 exit code |
| `assert_contains <pattern>` | 断言 stdout 包含指定文本 |
| `assert_not_contains <pattern>` | 断言 stdout 不包含指定文本 |
| `assert_stderr_contains <pattern>` | 断言 stderr 包含指定文本 |
| `assert_file_exists <path>` | 断言文件存在 |
| `assert_dir_exists <path>` | 断言目录存在 |
| `begin_test <name>` | 标记测试名称 |
| `end_tests` | 输出结果汇总 + cleanup |

## 5. 性能测试

使用多档位阶梯方式，测试不同数据规模下的耗时：

| 档位 | 行数 | 用途 |
|------|------|------|
| 小 | 100 | 基线 |
| 中 | 1,000 | 日常规模 |
| 大 | 10,000 | 中型项目 |
| 超大 | 100,000 | 压力边界 |

性能测试流程：
1. 用 `util scaffold` 从 sanguo.tblschema 生成骨架
2. 用 `helpers/datagen.py` 按字段类型生成 N 行随机数据
3. 运行 CLI 命令并计时
4. 输出耗时表格

```bash
=== JSON Export Performance ===
Rows       Time(s)
100        0.05
1000       0.12
10000      0.89
100000     8.34
```
