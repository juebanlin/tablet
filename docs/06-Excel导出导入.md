# Excel 导出 / 导入

> 3.0 起 Tauri 移除「外部 Excel 编辑 + Excel 同步」：不再拉起 Excel、不再轮询 mtime 回写，
> 也不再有底部「Excel 文件」同步面板。唯一的表格编辑器是内置 Univer（@18）。
> 本文件只描述 Excel 的**导入 / 导出**能力。

## 1. 入口

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 导出 Excel… | 项目 / 组 / 节点右键 → 导出 ▸；或组右键 → Excel | 左树勾选多个组 / 节点，合成一本 `<project>-excel.xlsx` |
| 导入 Excel… | 项目 / 组右键 → 导入 ▸；或组右键 → Excel | 打开工作簿，按 sheet 逐行选择目标组 / 节点，可覆盖 / 改名 / 新建组 |
| 导入任意 Excel（映射） | 项目右键 | 任意布局：选表头 / 数据区 / id 列 + 源列→目标列映射 |
| 重新加载 | xlsx 组右键 | 从磁盘重读该工作簿（策划外部编辑后用） |
| CLI | `tablet-cli excel export/import` | 单组工作簿往返，见 @03 |

## 2. 工作簿布局

- **Table**：4 行表头 `desc / export / type / 字段名`，数据从第 5 行开始。
- **Constant**：1 行表头 `name | type | value | export | desc`，数据从第 2 行开始。
- **Enum**：1 行表头 `id | name | desc`，数据从第 2 行开始。

xlsx 组的结构与数据都以工作簿为准（manifest 只记录节点索引），详见 @02。

`date` 字段在 Excel 里写成**真实日期单元格**：底层是 1900 日期系统的序列值（不是毫秒数字），
显示格式固定 `yyyy-mm-dd hh:mm:ss`。回读时接受：
- Excel 日期单元格 / 序列值（现代日期约 4.5 万）；
- 直接填写的 Unix 毫秒时间戳（约 1.7 万亿，按量级区分）。

日期文本（如 `2024-01-01 12:00:00`）不是合法数据，导入后由验证层报错，不做自动猜测。
Excel 日期不带时区，序列值按本机墙上时间解释；同机导出再导入无损，跨时区共享时墙上时间不变。

## 3. 导出

- 选中多个组 / 节点 → 一本工作簿，一个节点一个 sheet；sheet 名 = 节点名。
- 导出只读取内存里的当前状态，不要求先保存；输出默认落在 `<project>/.excel/`。
- 代码路径：`tablet_core::excel::export_selected_book`；CLI 单组导出走 `export_group_book`。

## 4. 导入

- 先 `excel_inspect_workbook` 读工作簿：每张 sheet 的类型、表头行、数据起始行、列数、行数。
- 每一行（sheet）可选：目标组、目标节点名、是否新建组；同名目标默认覆盖，可改名。
- 导入前统一校验：目标重复、组 / 节点名非法、类型冲突、新建组与现有组撞名 → 整次拒绝。
- 所有 sheet 在一个 `edit_project("Excel 导入")` 事务里应用：**一次导入 = 一个撤销步**；回写只进内存，主界面点保存才落盘。
- 目标组可以是 Tbl 或 xlsx：Tbl 组写成 `config/<group>/<node>.tbl`，xlsx 组写进对应工作簿。
- 任意布局映射（@14）：自动识别类型与表头行，字段名规范化、类型推断、四行表头补齐。

## 5. 严格校验

- sheet 名与目标节点名必须合法（大写字母开头、英文数字下划线、≤31 字符）。
- Table 的 4 行表头缺失 / 列名非法 / export 无法解析 → 该 sheet 报错，不静默兜底。
- 引用的目标不存在、类型不匹配由后续验证（@02）报告，不阻断导入本身。

## 6. 剪贴板兼容（TSV）

表格内的复制 / 剪切 / 粘贴走浏览器剪贴板 `text/plain`：

- `\t` 分列、`\r\n` / `\n` 分行；
- Excel / WPS 会把含换行、制表符、引号的单元格用 `"..."` 包裹，内部 `""` 表示一个 `"`；
- 引号内换行属于单元格内容（多语言文案里常见），**不能拆成多行**；
- 复制回剪贴板用同一套规则加引号，保证往返一致。

实现见 `crates/app-tauri/ui/grid.js` 的 `parseTSV` / `tsvQuote`。

## 7. 已知限制

- 不支持从外部 Excel 直接回写内存（3.0 已移除）；请用「导入 Excel…」或 Univer 编辑。
- xlsx 组的「重新加载」要求组内没有未保存改动；外部工作簿有变更时主界面会轮询提示。
- 不支持合并单元格 / 图片 / 批注等富内容的语义导入（只按单元格文本处理）。
