## 2. Group 与 Excel 的对应关系

- 一个**文件夹** = 一个 **Group** = 一个 **Excel 文件**
- 文件夹内每个 `.tbl` 文件 = 一个 **Table / Constant / Enum** = Excel 中的一个 tab
- 用 Excel 编辑时整个 Group 生成一个 xlsx，每个配置项对应一个 tab（详见 @05）

Group 名仅在工具内部使用，不进生成代码路径，因此允许中文（@01.8.1、@04.1）。

## 4. tbl-tool.toml 配置

工具配置文件，定义项目目录、导出目标、UI 行为、类型分隔符。所有字段都有默认值，新建项目可只写少量字段。

### 4.1 完整示例

```toml
[project]
name = "game-config"
config_dir = "config"
cache_dir = ".tbl-cache"

[export]
encoding = "utf-8"
line_ending = "lf"

[export.json]
empty_as = "null"     # null / omit

[export.xml]
empty_as = "empty"    # empty / omit

[export.server]
data_output = "gen/server/data"

[export.server.java]
package = "com.game.config"
code_output = "gen/server/java"

[export.server.go]
package = "config"
code_output = "gen/server/go"

[export.client.lua]
output = "gen/client"

[ui]
auto_commit_on_blur = true
realtime_validate = false
log_level = "debug"

[separators]
Tuple2 = ","
Tuple3 = ","
Tuple4 = ","
List = ";"
Set = ";"

[separators.Map]
kv = ":"
entry = ";"

[separators.List_Tuple2]
tuple = ","
list = ";"

[separators.Map_Tuple2]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_List]
kv = ":"
item = ","
entry = ";"
```

### 4.2 [project]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| name | 项目名称 | — |
| config_dir | .tbl 文件所在目录（相对项目根） | — |
| cache_dir | 临时 xlsx 缓存目录 | `.tbl-cache` |

### 4.3 [export]（全局）

| 字段 | 说明 | 默认值 |
|------|------|--------|
| encoding | 生成文件编码 | utf-8 |
| line_ending | 换行符（lf / crlf） | lf |

子段（json/xml/server/client）可分别覆盖 `encoding` `line_ending`。

### 4.4 [export.json] / [export.xml]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| empty_as | json: `null` / `omit`； xml: `empty` / `omit` | json=null； xml=empty |

空值策略详见 @01.8.4。

### 4.5 [export.server]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| data_output | 后端数据文件目录（JSON/XML 共用） | — |

### 4.6 [export.server.java]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| package | Java 包名 | — |
| code_output | Java 模板类输出目录 | — |

### 4.7 [export.server.go]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| package | Go package | — |
| code_output | Go 代码输出目录 | — |

### 4.8 [export.client.lua]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| output | Lua 文件输出目录 | — |

### 4.9 [separators]

按范式配置类型分隔符，详见 @01.7.4。

默认值覆盖绝大多数场景，仅当项目有历史数据使用不同分隔符时才需要修改。

### 4.10 [ui]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| auto_commit_on_blur | 点击空白区域时自动保存当前编辑 | true |
| realtime_validate | 编辑单元格时实时验证（关闭时仅保存前验证） | false |
| log_level | 日志级别（debug / info / warn / error） | debug |

#### 4.10.1 realtime_validate 行为

| 取值 | 编辑时 | 保存时 |
|------|--------|--------|
| `false`（默认） | 不验证；红框只在保存校验失败后才出现 | 强制全量验证 |
| `true` | 每次单元格提交都立刻 revalidate 当前节点 | 同上 |

打开实时验证可以更早发现错误，但项目大时（>10 万条记录）每次按键提交都会触发 cell+row+schema 三层调用，可能感知到卡顿。校验逻辑详见 @01.8 与 @01 附录 A。

UI 上的视觉反馈（红框/树节点 `!` /日志框）见 @02.5.4。

## 6. 内部数据模型

工具运行时的内存结构，定义在 `crates/core/src/model.rs`。

```rust
pub struct Project {
    pub workdir: PathBuf,
    pub config: ProjectConfig,
    pub groups: Vec<Group>,
}

/// 一个 Group = config/ 下一个子目录 = 一个 Excel 文件
pub struct Group {
    pub name: String,
    pub dir: PathBuf,
    pub tables: Vec<Table>,
    pub constants: Vec<Constant>,
    pub enums: Vec<Enum>,
}

/// Table = 行列数据配置（@01.4.1）
pub struct Table {
    pub name: String,
    pub path: PathBuf,
    pub schema: TableSchema,
    pub record_count: usize,
}

pub struct TableSchema {
    pub fields: Vec<FieldDef>,  // 第一列固定为 id (主键)
}

pub struct FieldDef {
    pub name: String,
    pub desc: String,
    pub tbl_type: String,   // TblFieldType 字符串，详见 @01.7
    pub export: Export,
}

/// Constant = 离散常量配置（@01.4.2）
pub struct Constant {
    pub name: String,
    pub path: PathBuf,
    pub entries: Vec<ConstEntry>,
}

pub struct ConstEntry {
    pub name: String,
    pub tbl_type: String,
    pub value: String,
    pub export: Export,
    pub desc: String,
}

/// Enum = 枚举配置（@01.4.3）
pub struct Enum {
    pub name: String,
    pub path: PathBuf,
    pub entries: Vec<EnumEntry>,
}

pub struct EnumEntry {
    pub id: i64,
    pub name: String,
    pub desc: String,
}

pub enum Export {
    ClientServer,  // 前后端 → cs
    ClientOnly,    // 客户端 → c
    ServerOnly,    // 服务器 → s
    None,          // 不导出 → -
}
```

`FieldDef.tbl_type` / `ConstEntry.tbl_type` 字符串都是 [TblFieldType](01-tbl系列格式与类型系统.md#7-tblfieldtype-类型系统)，工具内部解析为 `tbl_core::types::TblType` AST，详见 @01.7。

## 7. 节点状态与脏标记

每个节点（Group/Table/Constant/Enum）额外维护：

```rust
pub struct NodeState {
    pub original: Option<String>,  // 文件原始内容；None = 新建
    pub deleted: bool,             // 标记删除
    pub errors: Vec<NodeError>,    // 上次验证累积的错误
}
```

判定规则：

- `original = None` → 新建未保存
- 当前序列化 ≠ original → 脏（modified）
- `deleted = true` → 标记删除
- 改回 original 自动清除脏标记

UI 上的展示见 @02.2.2。

## 8. RefIndex 跨表索引

pub struct RefIndex {
