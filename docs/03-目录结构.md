# 目录结构

## 项目目录（策划仓库）

```
game-config/
├── config/                     ← .tbl 文件，纳入 Git
│   ├── hero/                   ← Group（对应一个 Excel）
│   │   ├── HeroBase.tbl       ← Table
│   │   ├── HeroSkill.tbl      ← Table
│   │   └── HeroConst.tbl      ← Constant（与 Table 共存）
│   ├── item/
│   │   ├── ItemBase.tbl
│   │   └── ItemDrop.tbl
│   ├── global/
│   │   └── GlobalConst.tbl    ← Constant
│   └── monster/
│       ├── MonsterAI.tbl       ← Table
│       └── MonsterConst.tbl    ← Constant
├── gen/                        ← 生成产物
│   ├── server/                 ← 后端
│   │   ├── data/               ← JSON 数据文件（按 Group 分目录）
│   │   └── code/               ← Java 模板类
│   │       └── com/game/config/
│   └── client/                 ← 前端（Lua，数据内嵌，按 Group 分目录）
│       └── config/
├── .tbl-cache/                 ← 临时 xlsx + .tbl.tmp，gitignore
├── tbl-tool.toml               ← 项目配置
└── .gitignore
```

## Group 与 Excel 的对应关系

- 一个**文件夹** = 一个 **Group** = 一个 **Excel 文件**
- 文件夹内每个 `.tbl` 文件 = 一个 **Table** 或 **Constant** = Excel 中的一个 tab
- 用 Excel 编辑时，整个 Group 生成一个 xlsx，每个 Table/Constant 对应一个 Excel tab

## 工具目录

```
tbl-tool/
├── Cargo.toml
├── types.toml                  ← 类型分隔符配置
├── src/
│   ├── main.rs
│   ├── app.rs                  ← egui App 状态 + 主循环
│   ├── ui/
│   │   ├── mod.rs
│   │   ├── tree.rs             ← 左侧资产树
│   │   ├── editor.rs           ← 右侧数据编辑
│   │   ├── schema_editor.rs    ← 表头编辑（含类型下拉）
│   │   └── status.rs           ← 底部状态栏
│   ├── core/
│   │   ├── mod.rs
│   │   ├── project.rs          ← 扫描目录，构建资产树
│   │   ├── tbl.rs              ← .tbl 解析/序列化
│   │   ├── types.rs            ← 类型系统 + 分隔符配置
│   │   ├── excel.rs            ← tbl ↔ xlsx 互转
│   │   ├── bridge.rs           ← 打开 Excel + 监听关闭 + 写回
│   │   └── codegen.rs          ← 代码生成（数据/前端/后端）
│   └── model.rs                ← 数据模型定义
└── tests/
```
