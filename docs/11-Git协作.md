# Git 协作

## 冲突最小化策略

| 策略 | 效果 |
|------|------|
| 一行一记录 | 不同策划改不同行，Git 自动 merge |
| 按 Group 分文件夹 | 不同策划改不同表，无冲突 |
| 主键排序 | 行顺序稳定，不因排序产生 diff |
| schema 与数据同文件 | 减少文件数，简化管理 |

## 冲突场景

| 场景 | 概率 | 解决方式 |
|------|------|----------|
| 不同策划改不同表 | 最常见 | 无冲突 |
| 不同策划改同表不同行 | 常见 | Git 自动 merge |
| 不同策划改同一行 | 极少 | Git 标记冲突，手动解决（文本格式易读） |
| schema 变更 | 极少 | 需协调，一人改 schema 后通知其他人 |
