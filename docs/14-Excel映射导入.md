# Excel 映射导入（计划）

> 状态：Phase A 与多 Sheet tabs 已实现，待验收。任意 Excel 映射成 tablet 结构；
> 每个 Sheet 独立映射，可导入当前或全部。Constant/Enum、映射方案复用、可选 xlsx 输出仍待做。

## 1. 目标与非目标

### 1.1 目标

- 源 Excel 可以是任意布局：id 不在第一列、只有一行列名、列名大小写/空格/中文不统一。
- 用户选择表头行、数据起始行、id 列，并把源列映射到 tablet 字段。
- 自动规范化字段名（snake_case）、推断类型、补 `desc / export / type / field` 四行表头。
- 预览映射结果，校验通过后导入。
- 源 Excel **不被修改**。

### 1.2 非目标

- 不把源 Excel 的样式、合并单元格、公式、批注带进 tablet。
- 不自动理解任意业务语义；列映射必须可见、可改。
- 不在本阶段支持多 sheet 批量映射（Phase B）。
- 不替代「原生 xlsx 组导入」：4 行表头合规的工作簿仍原样复制、保留样式。

## 2. 入口与判定

Project 根右键：

```text
导入 Excel Group...          ← 原生：4 行表头合规，原样复制
导入任意 Excel（映射）...    ← 本功能
```

选择文件后先做一次检测：

| 检测结果 | 行为 |
|---|---|
| 所有 sheet 都是 4 行规则表头 | 提示可直接走「导入 Excel Group」，也可继续映射 |
| 任一 sheet 不合规 | 打开映射窗口 |

映射窗口不修改源文件；输出默认写入当前 Project 的 `config/<group>/`（Tbl 组）。

### 3.2 A：原始数据

- 全宽只读预览，显示当前 tab 对应 sheet 的前 ~30 行；
- 顶部设置表头行、数据起始行，可「自动识别」；
- 可选语义行：描述行 / 类型行 / 导出行，**0 = 没有**；
  - 自动识别会把它们填上；识别不到保持 0；
  - 设置后，B 的目标字段会自动带出 desc / type / export；
  - 类型值必须能解析，export 只认短码或中文展示值；非法值在导入时阻止。
- 不在 A 中修改源数据；数据始终来自原 Excel。

### 3.3 B：映射调整

**B 左：源列勾选**

- 显示当前 sheet 的全部源列，每列一个勾选框；
- 勾选 = 加入右侧目标字段；取消勾选 = 从映射中移除；
- 已勾选的列显示目标字段，未勾选显示「忽略」；
- 没有再提供右侧「删除」按钮，增删只由左侧勾选控制；
- 只显示列名/映射状态，不显示数据（数据看 A）。

**B 右：目标字段**

- 节点名（每个 sheet 独立）；
- 目标字段表：目标字段 / 源列 / 类型 / export / desc；
- 把字段名改成 `id` 会自动置顶；id 类型必须是 int；
- 添加/删除字段，自动匹配只做建议。

### 3.4 C：最终效果

- 四行表头：`desc / export / type / field`；
- 映射后的数据前几行（id 在首列）；
- 导入前在这里确认列顺序、字段名和值。

### 3.5 Sheet tabs 与底部操作栏

- 每个 sheet 一个 tab，状态点：
  - 绿 = 可导入；
  - 红 = 有阻断错误；
  - 灰 = 待映射/无字段。
- 每个 tab 独立保存表头行、数据起始行、节点名、字段映射；切换 tab 不丢状态。
- 底部固定显示就绪数量与错误；按钮固定在弹窗内：
  - 导入当前 Sheet：仅当当前 tab 校验通过；
  - 导入全部：导入所有校验通过的 sheet，跳过失败的并在日志里列出；
  - 取消：不落任何数据。

## 4. 规范化规则

### 4.1 字段名

```text
ID / Id / id              → id
Hero Name / heroName      → hero_name
HP / Hp / hp              → hp
描述                       → 保留中文？→ 拒绝，要求用户改成英文 snake_case
```

- 只保留 ASCII 字母、数字、下划线；
- 大写转小写；空格、连字符、点、括号转下划线；
- 连续下划线合并；首尾下划线去掉；
- 首字符必须是字母；数字开头前加 `f_`（或直接要求用户改）；
- 与 tablet 关键字冲突时提示用户改；
- 最终必须匹配 `[a-z][a-z0-9_]*`。

### 4.2 节点名

- sheet 名默认转 PascalCase：去分隔符、首字母大写；
- 必须匹配 `[A-Z][A-Za-z0-9_]*`；
- 项目内唯一（忽略大小写）；冲突直接报错，不自动 `_copy`。

### 4.3 类型

- 采样前 ~200 行非空值：
  - 全部整数 → `int`
  - 全部数字（含小数）→ `float`
  - 全部 `true/false` → `bool`
  - 其它 → `str`
- 用户必须能覆盖；Phase A 固定提供 `int / float / bool / str / txt`，复合类型 / `@Ref` 在 Phase B 再做。
- 推断结果只是建议，不静默决定最终类型。

### 4.4 export / desc

- export 默认 `cs`，可逐列改；
- desc 优先取「描述 / desc / 说明」列；没有则用源列名或留空；
- id 的 desc 默认 `ID`。

## 5. 输出语义

### 5.1 默认：生成 Tbl 组

- 在 `config/<group>/<Node>.tbl` 写出 tablet v3 表头 + 数据；
- 写入 manifest 的 section 索引；
- 源 Excel 不动；
- 与 `project import-tbl` 共用同一套名字校验 / 冲突规则。

### 5.2 可选：生成 xlsx 组（Phase B）

- 生成新的 `config/<group>.xlsx`，写入 4 行表头；
- **不保留源表样式、合并、公式**；必须显式勾选并提示；
- 如果用户想要样式，应保留原工作簿并用原生 xlsx 导入，而不是映射。

## 6. Phase A 实现拆分

1. **core：映射计划与预览**
   - `SheetPreview { columns, rows, max_row, ... }`；
   - `MappingPlan { sheet, header_row, data_start, id_col, fields }`；
   - `normalize_field_name` / `infer_type` / `build_table` 纯函数 + 单测。
2. **core：导入**
   - `apply_mapping_to_project(project_id, group, plan)`；
   - 全量校验后写 `.tbl` + manifest；
   - 失败不落数据。
3. **GUI**
   - 新对话框 `dialogs/excel_mapping_dialog.slint`；
   - 状态 `AppState.excel_mapping`；
   - Project 根右键入口；
   - 预览 / 校验 / 导入接线。
4. **测试**
   - 单 header 行、id 不在第一列、大小写混乱、缺 id、字段名冲突；
   - 源文件字节不变；
   - 导入后 manifest / `.tbl` 正确。

## 7. 验收标准

1. 任意单 sheet Excel（只有一行表头、id 不在第一列）能完成映射并生成正确 `.tbl`。
2. 预览中能看到最终四行表头和数据前几行。
3. 字段名自动规范化；冲突、缺 id、非法类型会阻止导入。
4. 源 Excel 字节不变。
5. 导入后项目树、manifest、保存/导出行为正常。
6. 合规的 xlsx 仍走原生导入，样式保留。
