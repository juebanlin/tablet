# 项目配置

## tbl-tool.toml

```toml
[project]
name = "game-config"
config_dir = "config"
cache_dir = ".tbl-cache"

[export]
# 生成文件编码: utf-8 (默认)
encoding = "utf-8"
# 生成文件换行符: lf (默认), crlf
line_ending = "lf"

[export.json]
# 空值表达: "null" (默认, 输出 null) | "omit" (不输出字段)
empty_as = "null"

[export.xml]
# 空值表达: "empty" (默认, 输出空元素) | "omit" (不输出元素)
empty_as = "empty"

[export.server]
data_output = "gen/server/data"

[export.server.java]
package = "com.game.config"
code_output = "gen/server/java"

[export.server.go]
package = "config"
code_output = "gen/server/go"

[export.client.lua]
output = "gen/client"

[ui]
auto_commit_on_blur = true
realtime_validate = false
log_level = "debug"

[separators]
Tuple2 = ","
Tuple3 = ","
Tuple4 = ","
List = ";"
Set = ";"

[separators.Map]
kv = ":"
entry = ";"

[separators.List_Tuple2]
tuple = ","
list = ";"

[separators.Map_Tuple2]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_List]
kv = ":"
item = ","
entry = ";"
```

## 字段说明

### [project]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| name | 项目名称 | — |
| config_dir | .tbl 文件所在目录（相对项目根） | — |
| cache_dir | 临时 xlsx 缓存目录 | `.tbl-cache` |

### [export]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| encoding | 生成文件编码 | utf-8 |
| line_ending | 换行符风格（lf / crlf） | lf |

### [export.json]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| empty_as | 空值表达方式：`null`（输出 null）/ `omit`（不输出字段） | null |
| line_ending | 换行符风格（覆盖全局） | 继承 [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export] |

### [export.xml]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| empty_as | 空值表达方式：`empty`（输出空元素）/ `omit`（不输出元素） | empty |
| line_ending | 换行符风格（覆盖全局） | 继承 [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export] |

### [export.server]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| data_output | 后端数据文件输出目录（JSON/XML 共用） | — |
| line_ending | 换行符风格（覆盖全局） | 继承 [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export] |

### [export.server.java]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| package | Java 包名 | — |
| code_output | Java 模板类输出目录 | — |
| line_ending | 换行符风格（覆盖全局） | 继承 [export.server] → [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export.server] → [export] |

### [export.server.go]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| package | Go package name | — |
| code_output | Go 代码输出目录 | — |
| line_ending | 换行符风格（覆盖全局） | 继承 [export.server] → [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export.server] → [export] |

### [export.client]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| line_ending | 换行符风格（覆盖全局） | 继承 [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export] |

### [export.client.lua]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| output | Lua 文件输出目录 | — |
| line_ending | 换行符风格（覆盖全局） | 继承 [export.client] → [export] |
| encoding | 文件编码（覆盖全局） | 继承 [export.client] → [export] |

### [ui]

| 字段 | 说明 | 默认值 |
|------|------|--------|
| auto_commit_on_blur | 点击空白区域时自动保存当前编辑 | true |
| realtime_validate | 编辑单元格时实时验证 | false |
| log_level | 日志级别 (debug/info/warn/error) | debug |

### [separators]

按范式配置类型分隔符，详见 [02-类型系统](02-类型系统.md#分隔符配置)。

默认值覆盖绝大多数场景，仅当项目有历史数据使用不同分隔符时需修改。
