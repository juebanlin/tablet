### 布局分区（从上到下、从左到右）

| 区域 | 位置 | 尺寸 | 内容 |
|------|------|------|------|
| 左侧面板 | 左侧 | 默认200px，可拖拽，最小80px | 过滤器 + 树形导航 |
| 工具栏 | 顶部 | 固定高度 | 全局按钮（生成测试/清空/Excel/保存/重载） |
| 编辑栏 | 表格上方 | 22px | 坐标标签 + 单元格内容编辑框 |
| 表格区 | 中部填充 | 自适应 | 固定表头 + 可滚动数据区 |
| 状态栏 | 日志上方 | 20px | 选中信息 + 光标位置 |
| 日志栏 | 底部全宽 | 120px 默认，可拖拽 | 操作日志滚动展示 |

左侧面板与右侧内容区通过可拖拽分隔线调节比例。面板调窄时，树内容超出宽度会出现水平滚动条。

## 左侧树形结构

### 交互方式

| 操作 | 效果 |
|------|------|
| 点击三角形(▶/▼) | 展开/收拢组 |
| 双击组名 | 展开/收拢组 |
| 单击配置项 | 选中，右侧显示详情 |
| 右键任意位置 | 弹出对应上下文菜单 |

### 状态标记

节点名后显示彩色状态标记：

| 标记 | 颜色 | 含义 |
|------|------|------|
| `+` | 绿色 | 新建，未保存到磁盘 |
| `*` | 黄色 | 已有文件被修改 |
| `-` | 红色 | 标记删除，保存时生效 |

组的状态聚合子项：所有子项删除→`-`，有新建子项或自身新建→`+`，有修改子项→`*`。

判断逻辑：
- 新建：`original` 为空（从未保存过）
- 修改：序列化当前内容 ≠ `original`（支持"改回去"自动清除脏标记）
- 删除：`deleted` 标记为 true

### 过滤器

树顶部有下拉过滤框：

| 选项 | 显示内容 |
|------|----------|
| 全部 | 所有节点 |
| 改动 | 新增 + 修改 + 删除 |
| 新增 | 仅新建节点 |
| 修改 | 仅已修改节点 |
| 删除 | 仅标记删除节点 |

非"全部"模式下，空组自动隐藏。可勾选"完整组"显示匹配组的所有子项。

### 右键菜单

| 目标 | 菜单项 |
|------|--------|
| Group 节点 | 新建 Table、新建 Constant、重命名、删除 |
| Table/Constant 节点 | 复制、重命名、删除 |
| 空白区域 | 新建 Group |

## 表格区

### 单元格类型系统（CellKind）

所有单元格统一抽象为 CellKind，通过类型决定交互行为：

| 类型 | 交互方式 | 用途 |
|------|----------|------|
| ReadOnly | 不可编辑 | 常量表固定表头 |
| Text | 双击编辑 | 普通数据、表头描述/字段名 |
| TypeEnum | 单击下拉 | 表头 type 行单元格 |
| ExportEnum | 单击下拉 | 表头 export 行单元格 |
| TypeEnumCol | 单击下拉 | 常量表 type 列（整列继承） |
| ExportEnumCol | 单击下拉 | 常量表 export 列（整列继承） |
| Reference | 单击下拉搜索（预留） | 关联其他配置表主键 |

### Table 模式

4行固定表头 + 可滚动数据区：

```
┌────┬──────┬──────┬──────┬────────┐
│    │  A   │  B   │  C   │   D    │  ← 列字母行
├────┼──────┼──────┼──────┼────────┤
│    │英雄ID│ 名称 │ 血量 │ 技能组 │  ← desc (Text, 双击编辑)
│    │前后端│前后端 │服务器│ 前后端 │  ← export (ExportEnum, 单击下拉)
│    │ int  │ str  │ int  │IntArray│  ← type (TypeEnum, 单击下拉)
│    │ id   │ name │ hp   │ skills │  ← field (Text, 双击编辑)
╞════╪══════╪══════╪══════╪════════╡
│  1 │ 1001 │ 战士 │ 100  │ 1;2;3  │  ← 数据行 (Text, 双击编辑)
│  2 │ 1002 │ 法师 │  80  │ 4;5    │
│  3 │      │      │      │        │  ← 扩展空行（自动追加5行）
└────┴──────┴──────┴──────┴────────┘
```

- 表头固定不随数据滚动
- 数据行数 = 第一列（ID列）非空的行数
- 扩展空行允许直接输入新增数据

### Constant 模式

1行固定表头 + 可滚动数据区：

```
┌────┬──────────┬──────┬───────┬──────┬──────────┐
│    │  A       │  B   │  C    │  D   │  E       │
├────┼──────────┼──────┼───────┼──────┼──────────┤
│    │ name     │ type │ value │export│ desc     │  ← 固定表头 (ReadOnly)
╞════╪══════════╪══════╪═══════╪══════╪══════════╡
│  1 │max_level │ int▾ │ 100   │前后端▾│最大等级  │
│  2 │start_pos │IntPair▾│ 5,10│前后端▾│出生坐标  │
└────┴──────────┴──────┴───────┴──────┴──────────┘
```

列定义：
- name (Text) / type (TypeEnumCol▾) / value (Text) / export (ExportEnumCol▾) / desc (Text)

## 交互功能

### 选中

| 操作 | 结果 | 视觉反馈 |
|------|------|----------|
| 单击单元格 | 选中单格 | 浅蓝背景 + 蓝色边框 |
| 单击行号 | 选中整行 | 整行浅蓝背景 |
| 单击列字母 | 选中整列 | 整列浅蓝背景（含表头） |
| 从单元格拖动 | 选中矩形区域 | 区域浅蓝背景 |
| 从行号拖动 | 选中多行 | 多行浅蓝背景 |

### 编辑

| 操作 | 触发条件 | 行为 |
|------|----------|------|
| 文本编辑 | 双击 Text 类型单元格 | 弹出文本输入框，Enter 确认，Esc 取消 |
| 枚举选择 | 单击枚举类型单元格 | 弹出下拉选项列表，点击选中 |
| 公式栏编辑 | 选中 Text 单元格后在编辑栏输入 | Enter 提交修改 |
| 自动保存 | 编辑中点击其他位置 | 受 `auto_commit_on_blur` 配置控制（见下） |

### 编辑保存策略

通过 `tbl-tool.toml` 的 `[ui] auto_commit_on_blur` 配置：

| 设置值 | Enter | 点击空白/其他单元格 |
|--------|-------|---------------------|
| true（默认） | 保存 | 自动保存 |
| false | 保存 | 丢弃编辑 |

无论设置如何，Enter 始终保存，Esc 始终取消。

### 快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| Ctrl+C | 复制 | TSV 格式，兼容 Excel 粘贴 |
| Ctrl+V | 粘贴 | 解析 TSV，支持多行多列 |
| Delete / Backspace | 删除 | 清空选中单元格内容 |

### 右键菜单

| 目标 | 菜单项 |
|------|--------|
| 列字母行 | 左侧插入列、右侧插入列、删除列 |
| 行号 | 上方插入行、下方插入行、删除行 |
| 数据单元格 | 复制、粘贴、删除内容 |

## 编辑栏（公式栏）

位于表格上方，类似 Excel 公式栏：
- 左侧显示当前选中单元格坐标（如 "B3"）
- 右侧显示/编辑单元格完整内容
- 解决单元格内容过长被截断的问题
- 仅 Text 类型可编辑，枚举类型只读显示

## 状态栏

位于日志框上方，显示当前选中状态：

| 选中类型 | 显示内容 |
|----------|----------|
| 单格 | "B3" |
| 矩形区域 | "B2:D5 (4行×3列，共12格)" |
| 单行 | "第3行" |
| 多行 | "第2-5行 (共4行)" |
| 整列 | "第B列" |
| 鼠标悬停 | 追加 "光标: C4" |

## 保存机制

### 延迟写盘

所有创建/修改/删除操作仅修改内存，不立即写磁盘：
- 新建 Group/Table/Constant → 内存中创建，标记 `is_new` / `dirty`
- 编辑数据 → 修改内存，通过序列化对比自动计算 dirty
- 删除 → 标记 `deleted`，节点仍在树中显示（带 `-`）
- 复制 → 内存中复制，标记为新建

### 保存按钮

点击保存时统一处理：
1. 新建组 → `create_dir_all`
2. dirty 的 Table/Constant → 序列化写入 .tbl 文件
3. deleted 的节点 → 删除 .tbl 文件，从内存移除
4. 空组 → 删除目录

未保存关闭程序 = 丢弃所有修改。

### 进程锁

同目录下 `.tbl-tool.lock` 文件防止多实例编辑同一项目。启动时检查 PID 是否存活。
