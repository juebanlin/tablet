## 2. 左侧树

### 2.1 交互

| 操作 | 效果 |
|------|------|
| 点击三角形 ▶/▼ | 展开/收拢组 |
| 双击组名 | 展开/收拢组 |
| 单击配置项 | 选中，右侧显示详情 |
| 右键 | 弹出对应上下文菜单 |

### 2.2 状态标记

| 标记 | 颜色 | 含义 |
|------|------|------|
| `+` | 绿 | 新建未保存 |
| `*` | 黄 | 已有文件被修改 |
| `-` | 红 | 标记删除，保存时生效 |
| `!` | 红 | 节点存在验证错误（详见 @5.4） |

组的状态聚合子项：所有子项删除→`-`，有新建子项或自身新建→`+`，有修改子项→`*`。

判断：
- 新建：`original` 为空
- 修改：序列化当前内容 ≠ `original`（"改回去"自动清除脏标记）
- 删除：`deleted = true`

### 2.3 过滤器

| 选项 | 显示 |

| 修改 | 仅已修改节点 |
| 删除 | 仅标记删除节点 |

非"全部"模式下空组自动隐藏。可勾选"完整组"显示匹配组的所有子项。

## 3. 表格区

### 3.1 单元格类型系统（CellKind）

所有单元格统一抽象为 `CellKind`，决定交互行为：

| 类型 | 交互 | 用途 |
|------|------|------|
| ReadOnly | 不可编辑 | Constant/Enum 固定表头、Table id 字段名 |
| Text | 双击编辑 | 普通数据、表头 desc/field |
| TypeEnum | 单击弹出类型选择器 | Table 表头 type 行 |
| ExportEnum | 单击下拉 | Table 表头 export 行 |
| TypeEnumCol | 单击弹出类型选择器 | Constant type 列 |
| ExportEnumCol | 单击下拉 | Constant export 列 |
| Ref | 单击弹出引用选择器 | 列类型为 `@Xxx` 的数据格 |

### 3.2 存储值 vs 展示值（重要约定）

单元格在 UI 模型层（`grid.data` / `HeaderCell.text`）**始终存「真实存储值」**——即写入 .tbl 文件的形式。渲染层在画的瞬间通过 `display_for_*` 转换为 UI 展示值。

| 列类型 | 存储值（grid.data） | 展示值（painter） |
|--------|----------------------|-------------------|
| ExportEnum / ExportEnumCol | `cs` / `c` / `s` / `-` | 前后端 / 客户端 / 服务器 / 不导出 |
| Ref（@EnumName + 开关开） | enum 条目 id（如 `1`） | 对应 entry.name（如 `WARRIOR`） |
| Ref（@TableName 或开关关） | 表/枚举 id | 同存储值 |
| 其它 | 原字符串 | 同存储值 |

由此自动得到的好处：
- **复制粘贴 round-trip**：剪贴板永远是 `cs` 而不是「前后端」，粘到别处直接落地
- **公式栏/编辑缓冲一致**：编辑态读 `grid.data` 直接拿到存储值
- **校验/序列化无歧义**：底层逻辑只看一种字符串

下拉编辑组件按同规则：`edit_buffer` 写存储值（点击「前后端」实际写 `cs`），渲染时再翻译。新增带「展示≠存储」的列类型时，**必须同时在 `display_for_cell` / `display_for_header` 增加分支**，不允许把展示值塞回 `grid.data`。

### 3.3 Table 模式

```
┌────┬──────┬──────┬──────┬────────┐
│    │  A   │  B   │  C   │   D    │  ← 列字母行
├────┼──────┼──────┼──────┼────────┤
│    │英雄ID│ 名称 │ 血量 │ 技能组 │  ← desc (Text)
│    │前后端│前后端│服务器│ 前后端 │  ← export (ExportEnum)
│    │ int  │ str  │ int  │List<int>│ ← type (TypeEnum)
│    │ id   │ name │ hp   │ skills │  ← field (Text，id 列 ReadOnly)
╞════╪══════╪══════╪══════╪════════╡
│  1 │ 1001 │ 战士 │ 100  │ 1;2;3  │
│  2 │ 1002 │ 法师 │  80  │ 4;5    │
│  3 │      │      │      │        │  ← 扩展空行（自动追加 5 行）
└────┴──────┴──────┴──────┴────────┘
```

- 表头固定，不随数据滚动
- 数据行数 = 第一列（ID 列）非空的行数
- 扩展空行允许直接输入新增数据
- ID 列字段名固定 `id`，不可编辑/不可删除（见 @01.5.2）

## 5. 上层组件

### 5.1 工具栏

按钮：[生成测试数据] [清空配置] | [用Excel打开] [保存] [重新加载] | [导出] [导出Schema] [导入Schema]。详见 @6.3 / @6.4。

### 5.2 功能区 bar

位于工具栏与编辑栏之间，类似 Excel 工具栏下面那条「字体/对齐/换行」选项条：放视图开关，仅影响渲染，不改数据、不改公式栏行为。

```
┌─────────────────────────────────────────────────────────┐
│ [☑] 枚举显示名字   ...                                  │
└─────────────────────────────────────────────────────────┘
```

#### 当前开关

| 开关 | 作用 | 默认 |
|------|------|------|
| 枚举显示名字 | `@EnumName` 单元格只读渲染时显示 entry.name 而非 id | 关 |

#### 不参与切换

- 表引用 `@TableName` 始终显示 id（被引用表可能没有 `name` 字段）
- 编辑场景（公式栏 / 双击编辑）始终是 id（避免「看到名字、改的是 id」的割裂）

### 5.3 编辑栏（公式栏）

是单元格内置编辑组件的「长内容辅助查看 + 编辑」延伸：

- 左：当前选中单元格坐标（如 `B3`）
- 右：根据单元格类型决定行为

| 单元格类型 | 公式栏行为 |
|-----------|-----------|
| Text | 可编辑，缓冲 = 真实存储值；Enter / 失焦提交 |
| ExportEnum / ExportEnumCol | 只读展示（与单元格内一致：前后端/客户端/...）。编辑走单元格自身下拉框 |
| TypeEnum / TypeEnumCol | 只读展示类型字符串。编辑走类型选择器弹窗 |
| Ref | 只读展示 id（开关开时显示 enum name）。编辑走引用选择弹窗 |
| 表头单元格（desc/export/type/field 行） | 公式栏不参与，编辑由表头自身的双击/下拉处理 |

设计目的：解决 Text 单元格内容过长被截断（特色单元格内容本身就短，无此需求）。

### 5.4 验证错误展示

数据通过 cell→row→schema→project 四层验证（@01.8、@01 附录 A），UI 上的错误反馈：

| 位置 | 表现 |
|------|------|
| 表格单元格 | 红色边框（1.5px） |
| 树节点 | 状态标记后追加红色 `!` |
| 组节点 | 子项有错误时同样追加 `!`（聚合） |
| 日志框 | 保存失败时输出具体错误位置 + 错误信息 |

实时验证开关 `[ui] realtime_validate` 见 @07.4.10.1。

### 5.5 状态栏

显示当前选中状态：

| 选中类型 | 显示 |
|---------|------|

| 矩形区 | `B2:D5 (4行×3列，共12格)` |

- 左侧选范式，右侧填参数（每个 `_` 从基础类型选）

- 实时预览：完整类型名 / 示例值 / Java/Go/Lua 声明

#### Tab 2 引用类型

```
┌─ 选择类型 ────────────────────────────────────────┐
│  [数据类型] [引用类型]                            │

│  搜索: [_______________]                          │
│  ┌─ 项目内可引用的项 ────────────────────────────┐│
│  │ ○ 📊 HeroBase     (table)                    ││
│  │ ● 🔢 HeroType     (enum)                     ││
│  │ ○ 📊 SkillBase    (table)                    ││
│  │ ○ 🔢 ItemQuality  (enum)                     ││
```

- 列出项目所有非删除 Table + Enum，带 📊/🔢 图标（constant 不可被引用，不出现）
- chip 过滤行单选切换
- 搜索框模糊匹配名称
- 选中后类型字符串为 `@XxxName`

#### 上下文限制

- **constant 表的字段类型不允许引用**：在 constant 表打开选择器时，[引用类型] tab 整个禁用（灰色 + 提示「constant 不允许引用类型」）
- **复合类型不能套引用**：`List<@HeroType>` 等组合不合法（解析层已拦截），UI 上不暴露这种入口

详见 @01.7.5、@01.7.6。

## 7. 保存机制

### 7.1 延迟写盘

所有创建/修改/删除操作只改内存，不立即落盘：
- 新建 Group/Table/Constant/Enum → 内存创建，标记 `is_new` / `dirty`
- 编辑数据 → 改内存，序列化对比自动计算 dirty
- 删除 → 标记 `deleted`，节点仍在树中显示（带 `-`）
- 复制 → 内存复制，标记新建

### 7.2 保存按钮

点击保存时统一处理：
1. 新建组 → `create_dir_all`
2. dirty 节点 → 序列化写 .tbl
3. deleted 节点 → 删除 .tbl 文件，从内存移除
4. 空组 → 删除目录

未保存关闭程序 = 丢弃所有修改。

### 7.3 进程锁

同目录下 `.tbl-tool.lock` 防止多实例编辑同一项目。启动时检查 PID 是否存活。

## 8. 行颜色标记展示

数据行带 `#@c:RRGGBB` 标记时，UI 表格中该行显示对应背景色（详见 @01.9）：

- 仅展示，不提供标色入口（标色在 Excel 中完成）
- 行号列同步显示颜色，便于快速识别

## 9. 退出提示（规划中）

未保存修改时退出 → 弹出确认（保存 / 放弃 / 取消）。

## 10. 图标参考

工具使用 Unicode emoji/符号作为 UI 图标，egui 原生渲染无需额外图标库。

### 10.1 已使用

| 符号 | 用途 |
|------|------|
| 📁 | Group 文件夹 |
| 📊 | Table |
| 📋 | Constant |
| 🔢 | Enum |
| ▶ ▼ | 树展开箭头 |
| ☑ ☐ ▣ | 复选框（含半选） |
| ✅ ⚠️ | 状态（新增 / 已存在覆盖） |

### 10.2 候选符号

**状态**：❌ ❗ ✔️ ⏳ 🔄 🚫

**操作**：➕ ➖ ✏️ 🔍 💾 📥 📤 🗑️ 📎

**标记**：🟢 🟡 🔴 ⬤ ○ ● ◆ ◇ ★ ☆

**结构**：📄 📂 🏷️ 🔗 📐 ⚙️

### 10.3 框架兼容性

| 框架 | 彩色 emoji | 单色符号 | 备注 |
|------|-----------|---------|------|
| egui | ✅ | ✅ | 走系统字体 fallback，开箱即用 |
| Slint | ✅ | ✅ | 需确保字体 fallback 链含 emoji 字体 |
| fltk | ❌ | ✅ | 字体引擎不解析 color emoji 表（COLR/CBDT/sbix） |

fltk 兼容替代见 @03.

### 10.4 使用建议

- egui 默认字体支持大部分 emoji 渲染
- 组合符号（如 ⚠️ = U+26A0 + U+FE0F）在某些字体下可能显示为文本样式
- 单色符号（▶▼☑☐▣●○）渲染最稳定
- 彩色 emoji 依赖系统字体，Windows/macOS 表现一致
