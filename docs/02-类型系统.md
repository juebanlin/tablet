# 类型系统

## 设计原则

- 类型采用**范式 + 泛型参数**架构，范式有限枚举，参数从基础类型中选择
- 类型定义**内置于工具**，不跟随项目仓库
- 配置文件按范式配置**分隔符参数**
- 支持多后端（Java / Go）和前端（Lua）代码生成

## 基础类型（6个）

| 类型 | 说明 | Java | Go | Lua |
|------|------|------|----|-----|
| int | 32位整数 | int | int32 | number |
| long | 64位整数 | long | int64 | number |
| float | 单精度浮点 | float | float32 | number |
| double | 双精度浮点 | double | float64 | number |
| str | 字符串 | String | string | string |
| bool | 布尔 | boolean | bool | boolean |

## 元组类型

| 类型 | 说明 | Java | Go | Lua |
|------|------|------|----|-----|
| Tuple2\<P,P\> | 二元组 | P[2] 或 Tuple2 类 | [2]P / struct | {p1, p2} |
| Tuple3\<P,P,P\> | 三元组 | P[3] 或 Tuple3 类 | [3]P / struct | {p1, p2, p3} |
| Tuple4\<P,P,P,P\> | 四元组 | P[4] 或 Tuple4 类 | [4]P / struct | {p1, p2, p3, p4} |

## 集合类型

| 类型 | 说明 | Java | Go | Lua |
|------|------|------|----|-----|
| List\<T\> | 有序列表 | List\<T\> | []T | {v1, v2, ...} |
| Set\<P\> | 无重复集合 | Set\<P\> | map[P]struct{} | {[v]=true, ...} |
| Map\<K,V\> | 键值对 | Map\<K,V\> | map[K]V | {k1=v1, k2=v2} |

约束：
- Set 只支持基础类型作为元素（`Set<P>`）
- Map 的 K 只能是 `int | long | float | double | str`（排除 bool）
- Map 的 V 支持基础类型、元组、List\<P\>

## 范式枚举

所有合法的类型组合（2层分隔符内可表达）：

### 0层（无分隔符）

| 范式 | 示例值 |
|------|--------|
| P | `100`, `hello`, `true` |

### 1层（单分隔符）

| 范式 | 示例值 | 分隔符 |
|------|--------|--------|
| Tuple2\<P,P\> | `5,10` | tuple |
| Tuple3\<P,P,P\> | `1,2,3` | tuple |
| Tuple4\<P,P,P,P\> | `1,2,3,4` | tuple |
| List\<P\> | `1;2;3` | list |
| Set\<P\> | `1;2;3` | set |
| Map\<P,P\> | `hp:100;mp:50` | kv + entry |

### 2层（双分隔符）

| 范式 | 示例值 | 分隔符 |
|------|--------|--------|
| List\<Tuple2\<P,P\>\> | `1,2;3,4;5,6` | tuple + list |
| List\<Tuple3\<P,P,P\>\> | `1,2,3;4,5,6` | tuple + list |
| List\<Tuple4\<P,P,P,P\>\> | `1,2,3,4;5,6,7,8` | tuple + list |
| Map\<P,Tuple2\<P,P\>\> | `atk:5,10;def:3,8` | kv + tuple + entry |
| Map\<P,Tuple3\<P,P,P\>\> | `hp:1,2,3;mp:4,5,6` | kv + tuple + entry |
| Map\<P,Tuple4\<P,P,P,P\>\> | `k:1,2,3,4;j:5,6,7,8` | kv + tuple + entry |
| Map\<P,List\<P\>\> | `hp:1,2,3;mp:4,5,6` | kv + item + entry |

注：范式中所有 `P` 位置均为独立选择的基础类型，同一范式内各 P 可以不同。

## 不支持的组合（需拆表处理）

- List\<List\<P\>\> — 外层和内层分隔符冲突
- Map\<P,Map\<P,P\>\> — 嵌套 Map 分隔符冲突
- List\<Map\<P,P\>\> — 同理
- Set\<Tuple\> — Set 只支持基础类型

## 分隔符配置

在 `tbl-tool.toml` 的 `[separators]` 段配置，按范式独立设定：

```toml
[separators]
# 元组分隔符
Tuple2 = ","
Tuple3 = ","
Tuple4 = ","
# 集合分隔符
List = ";"
Set = ";"

[separators.Map]
kv = ":"
entry = ";"

[separators.List_Tuple2]
tuple = ","
list = ";"

[separators.List_Tuple3]
tuple = ","
list = ";"

[separators.List_Tuple4]
tuple = ","
list = ";"

[separators.Map_Tuple2]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_Tuple3]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_Tuple4]
kv = ":"
tuple = ","
entry = ";"

[separators.Map_List]
kv = ":"
item = ","
entry = ";"
```

每个范式的分隔符含义自描述，互不影响。默认值覆盖绝大多数场景，仅历史数据兼容时需修改。

## 平台映射详表

### 基础类型

| .tbl 值 | Java | Go | Lua |
|---------|------|----|-----|
| `100` | int 100 | int32(100) | 100 |
| `100000` | long 100000L | int64(100000) | 100000 |
| `1.5` | float 1.5f | float32(1.5) | 1.5 |
| `3.14159` | double 3.14159 | float64(3.14159) | 3.14159 |
| `hello` | String "hello" | string "hello" | "hello" |
| `true` | boolean true | bool true | true |

### 元组

| 范式 | .tbl 值 | Java | Go | Lua |
|------|---------|------|----|-----|
| Tuple2\<int,int\> | `5,10` | int[]{5,10} | [2]int32{5,10} | {5,10} |
| Tuple2\<int,str\> | `1001,sword` | Tuple2(1001,"sword") | struct{int32,string} | {1001,"sword"} |
| Tuple3\<int,int,int\> | `1,2,3` | int[]{1,2,3} | [3]int32{1,2,3} | {1,2,3} |

### 集合

| 范式 | .tbl 值 | Java | Go | Lua |
|------|---------|------|----|-----|
| List\<int\> | `1;2;3` | List.of(1,2,3) | []int32{1,2,3} | {1,2,3} |
| Set\<int\> | `1;2;3` | Set.of(1,2,3) | map[int32]struct{}{...} | {[1]=true,[2]=true,[3]=true} |
| Map\<str,int\> | `hp:100;mp:50` | Map.of("hp",100,"mp",50) | map[string]int32{...} | {hp=100,mp=50} |

### 嵌套

| 范式 | .tbl 值 | Java | Go | Lua |
|------|---------|------|----|-----|
| List\<Tuple2\<int,int\>\> | `1,2;3,4` | List\<int[]\> | [][2]int32 | {{1,2},{3,4}} |
| Map\<str,Tuple2\<int,int\>\> | `atk:5,10;def:3,8` | Map\<String,int[]\> | map[string][2]int32 | {atk={5,10},def={3,8}} |
| Map\<str,List\<int\>\> | `hp:1,2,3;mp:4,5` | Map\<String,List\<Integer\>\> | map[string][]int32 | {hp={1,2,3},mp={4,5}} |

Lua 全部导出为 table 字面量，不降级为 string。

## UI 类型选择器

点击类型单元格弹出选择窗口，分步交互：

```
┌─────────────── 选择类型 ───────────────────────────┐
│                                                     │
│  ┌─ 范式 ──────────────┐  ┌─ 参数 + 预览 ────────┐ │
│  │ ○ 基础类型           │  │                       │ │
│  │ ○ Tuple2<_,_>       │  │  P1: [int ▼]          │ │
│  │ ○ Tuple3<_,_,_>     │  │  P2: [int ▼]          │ │
│  │ ○ Tuple4<_,_,_,_>   │  │                       │ │
│  │ ○ List<_>           │  │  结果: Tuple2<int,int> │ │
│  │ ○ Set<_>            │  │  示例: 5,10            │ │
│  │ ○ Map<_,_>          │  │  分隔符: ","           │ │
│  │ ○ List<Tuple2<_,_>> │  │                       │ │
│  │ ○ List<Tuple3<_,_,_>>│  │                       │ │
│  │ ○ List<Tuple4<_,_,_,_>>│ │                       │ │
│  │ ○ Map<_,Tuple2<_,_>>│  │                       │ │
│  │ ○ Map<_,Tuple3<_,_,_>>│ │                       │ │
│  │ ○ Map<_,Tuple4<_,_,_,_>>││                       │ │
│  │ ○ Map<_,List<_>>    │  │                       │ │
│  └─────────────────────┘  └───────────────────────┘ │
│                                                     │
│                            [ 确定 ]  [ 取消 ]        │
└─────────────────────────────────────────────────────┘
```

交互规则：
- 左侧选范式，右侧动态展示对应的参数下拉框
- 每个 `_` 位置从基础类型中选择（Map 的 K 排除 bool）
- 实时预览：显示完整类型名、示例值、当前分隔符配置
- 确定后写入字段的 tbl_type

## 类型值验证

已实现的验证规则：

| 检查项 | 说明 | 错误示例 |
|--------|------|----------|
| 基础类型格式 | int/long 必须是整数，float/double 必须是数字，bool 必须是 true/false | `"abc"` 作为 int |
| 元组元素数量 | Tuple2 必须恰好 2 个元素，Tuple3 恰好 3 个 | `"1,2,3"` 作为 Tuple2 |
| 元组元素类型 | 每个位置的值必须匹配对应基础类型 | `"1,abc"` 作为 Tuple2\<int,int\> |
| 列表/集合元素 | 每个元素必须匹配声明的基础类型 | `"1;abc;3"` 作为 List\<int\> |
| Map 格式 | 每个条目必须有 kv 分隔符，key 和 value 类型匹配 | `"hp100"` 缺少 `:` |
| 空元素检测 | 不允许连续分隔符产生的空值 | `"1;;3"` 或 `"1,,2"` |
| 中文标点检测 | 不允许 `，；：、` 等中文标点 | `"1，2，3"` |

验证错误自动附带示例提示（使用当前配置的分隔符）：
```
[验证] hero/HeroBase D2: "4,5" 列表元素类型不匹配, 示例: 1;2;3
```
