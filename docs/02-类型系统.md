# 类型系统

## 设计原则

- 类型定义**内置于工具**，不跟随项目仓库
- 配置文件仅允许修改类型的**分隔符参数**
- 后续新增类型通过工具升级发布

## 内置基础类型

| 类型 | 说明 | 默认分隔符 | Java 映射 | Lua 映射 |
|------|------|-----------|-----------|----------|
| int | 整数 | — | int | number |
| long | 长整数 | — | long | number |
| float | 浮点 | — | float | number |
| str | 字符串 | — | String | string |
| bool | 布尔 | — | boolean | boolean |

## 内置复合类型

| 类型 | 说明 | 默认分隔符 | 示例值 | Java 映射 | Lua 映射 |
|------|------|-----------|--------|-----------|----------|
| IntPair | (int, int) | `,` | 5,10 | int[2] | {5, 10} |
| StrPair | (str, str) | `,` | a,b | String[2] | {"a", "b"} |
| IntTriple | (int, int, int) | `,` | 1,2,3 | int[3] | {1, 2, 3} |
| Array\<T\> | T 的列表 | `;` | 1;2;3 | List\<T\> | {1, 2, 3} |
| Map\<K,V\> | 键值对 | `=` kv, `;;` 条目 | a=1;;b=2 | Map\<K,V\> | {a=1, b=2} |

## 分隔符配置

工具安装目录下的 `types.toml`：

```toml
# 仅配置分隔符，类型结构由工具内置
[separators]
IntPair = ","
StrPair = ","
IntTriple = ","
Array = ";"
Map.kv = "="
Map.entry = ";;"
```

策划无需关心此文件，仅当项目有历史数据使用不同分隔符时修改。

## UI 类型选择

表头编辑时，类型列提供下拉选择：
- 列出所有内置类型
- 选中后旁边显示格式示例（如选 `IntPair` → `示例: 5,10`）
- 复合类型显示当前分隔符配置

```
选择类型时：
┌─────────────┐
│ int         │
│ long        │
│ float       │
│ str         │
│ bool        │
│─────────────│
│ IntPair     │  →  示例: 5,10
│ StrPair     │  →  示例: hello,world
│ IntTriple   │  →  示例: 1,2,3
│ Array<int>  │  →  示例: 1;2;3
│ Array<str>  │  →  示例: a;b;c
│ Map<str,int>│  →  示例: hp=100;;mp=50
└─────────────┘
```
